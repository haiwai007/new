# 海神作图：项目概念与功能说明

## 1. 项目是什么

海神作图是一个本地优先的在线作图平台，帮助用户在浏览器里完成从参考图片、可编辑模板到成品图片的制作。

核心思路是：把设计拆成可编辑图层，把经常修改的内容设置为参数，再用同一套模板生成不同版本的图片。用户既可以直接修改文字、图片和样式，也可以像填写表单一样替换标题、价格、日期等内容，或设置参数规则批量生成图片。

平台适合宣传海报、社交配图、商品图、活动通知、节日祝福，以及手机界面展示图等场景。核心功能无需注册；账户与云端备份作为可选服务接入。

## 2. 产品原则

- **本地优先**：作品、模板、图片素材和历史版本默认保存在当前浏览器的 IndexedDB 中。
- **可编辑、可复用**：图层与参数是设计的基础，模板可以复制、修改、保存和再次使用。
- **操作可恢复**：支持撤销重做、历史版本、文件备份及恢复副本。
- **输出可验证**：根据设计数据重新渲染成品图片，导出质量不依赖编辑器当前的缩放比例。
- **服务状态明确**：未配置的云端功能显示“未启用”，操作失败时提供反馈。
- **资源由本站提供**：内置照片、展示字体与 OCR 引擎及模型随站点提供，常规本地流程无需请求第三方资源 CDN。

## 3. 几个核心概念

| 概念 | 含义 |
| --- | --- |
| 作品 | 一份正在制作或已经完成的设计，包含画布、图层、参数及相关设置 |
| 模板 | 可以重复使用的设计。用模板创建作品时会复制数据，后续各自编辑 |
| 图层 | 文字、图片、形状等独立元素，可调整位置、大小、样式、显示与锁定状态 |
| 参数 | 绑定到图层属性的可填写字段，例如标题、图片、颜色、字号、位置或日期文本 |
| 素材 | 存放在浏览器中的图片文件，可加入素材库或作为作品内部资源使用 |
| 历史版本 | 手动保存等操作产生的设计快照，可查看、备注、恢复或复制为新作品 |
| 云端备份 | 用户登录并手动上传的单个作品副本，用于后续下载到同一账户的其他浏览器 |

作品的文档数据是设计的主要记录。编辑器画布、预览、导出和备份围绕这份数据工作。

## 4. 主要功能

### 4.1 模板中心

提供具有真实图层数据的内置模板，支持分类浏览、收藏及创建新作品。新建作品时，内置照片会转为作品引用的本地素材，便于随模板文件和备份携带。

用户也可以把当前设计另存为自定义模板。修改自定义模板不会改动之前用它创建的作品。

### 4.2 上传图片与重建模板

支持上传 PNG、JPEG、WebP 图片，并提供三种处理方式：

| 方式 | 使用方式 |
| --- | --- |
| 智能重建 | 在浏览器中识别文字与位置，校正结果后生成可编辑文字图层及相关参数 |
| 原图背景 | 将参考图作为背景，在上面重建文字、添加图片框或遮罩 |
| 手动重建 | 使用锁定的参考图层，对照原图逐步搭建设计 |

图片中的文字由像素组成。OCR 可以提供文字内容与位置，用户仍需检查错字、漏字和排版结果。

背景修复使用本地算法，根据周围颜色填补旧文字区域，适用于纯色、渐变和简单纹理。复杂照片细节的还原能力有限；AI 照片级修复尚未接入。

### 4.3 图层编辑器

支持文字、图片、形状和背景编辑，以及图层排序、选择、对齐、组合、锁定、隐藏和复制。文字可调整字体、字号、颜色等属性；图片支持替换、适配和裁剪焦点等设置。

编辑器提供撤销重做、自动保存、手动保存、历史版本及预览。调整画布尺寸时，可以选择智能适配、等比缩放或保留元素位置与尺寸；手机状态栏会按新的画布尺寸重新贴合。

### 4.4 参数化设计

支持文字、多行文本、数字、日期、图片、颜色、字体、字号、选项、开关，以及尺寸、位置、旋转、透明度等参数类型。

参数可以设置分组、说明、默认值、必填条件和校验规则。例如，为商品图设置“商品名”“价格”“主图”参数后，用户可以直接填入新内容，继续沿用原来的排版。

### 4.5 手机机型与状态栏

在编辑器的“手机”工具中选择机型，配置手机屏幕展示图所需的信息。桌面端入口位于左侧工具栏，手机端入口位于底部工具栏。

提供按品牌分组的 62 个具体型号，其中安卓及鸿蒙机型 51 个，涵盖 Samsung、Google、小米、Redmi、华为、荣耀、OPPO、一加、vivo、iQOO 和 realme。完整型号、参考分辨率及系统样式见 [手机机型目录](PHONE_MODELS.zh-CN.md)。

上传生成模板页面也提供品牌与型号选择。选中后自动应用对应系统的时钟、电池和信号图形，匹配顶栏配色，并按当前图片画布适配；提供实际图片预览及旧状态栏覆盖高度调整。

可以调整：

- 时间及 24 / 12 小时格式，也可一次填入设备当前时间。
- 日期、中文月日、星期或 `YYYY-MM-DD` 格式。
- 0–100% 电量、百分比显示和充电状态。
- 蜂窝信号、Wi-Fi 强度、4G / 5G / LTE、飞行模式和蓝牙图标。
- 运营商名称及显示开关。
- 深浅图标配色、背景颜色、透明背景、开孔展示和底部手势条。

选择机型立即切换状态栏，默认保留当前画布。需要改变分辨率时，勾选“同时适配机型画布尺寸”，切换机型或点击重新应用。设置支持保存、撤销、历史版本和备份。

机型预设用于设计参考，不读取手机的真实系统状态。生成图层默认锁定，可在图层面板解锁。重新应用设置会重建并置顶这些图层；移除状态栏不会自动恢复之前的画布尺寸。

**保存图片时仅导出屏幕内容。** 时间、电量、日期等状态栏信息与底部手势条会保留；灵动岛、刘海、摄像头开孔等硬件装饰不进入成品图片。此规则适用于 PNG、JPEG、批量导出和导出预览。编辑器与模板备份继续保留原来的开孔设置，方便再次编辑。

### 4.6 批量生成

从模板库或已保存的参数化模板开始，设置生成张数及每个参数的规则：沿用模板、固定值、随机区间、随机时间段、候选值随机或自动编号。生成前显示参数校验和预览。

每组有效参数可生成一张 PNG，最终打包为 ZIP 下载。当前单次最多生成 200 张；失败项会明确列出，不计为成功生成。手机状态栏默认沿用模板，也可在独立的「状态栏随机」面板中按项启用随机。

### 4.7 作品、素材和版本管理

“我的作品”集中展示编辑项目与自定义模板，支持搜索、收藏、重命名、复制、继续编辑、查看历史、删除和模板文件导入导出。

素材库支持图片预览、名称与分类管理，并在删除前检查引用关系。历史版本可以添加备注、恢复或复制为新作品。导出记录保存文件名、格式、尺寸和来源信息，已下载的成品图片文件由用户自行保管。

### 4.8 备份与恢复

| 方式 | 内容 | 当前上限 |
| --- | --- | --- |
| 单个模板文件 | 当前文档、参数和引用的本地图片 | 80MB |
| 完整本地备份 | 作品与模板、保留的历史版本、素材库、导出记录及内置模板收藏 | 100MB |
| 云端单个作品备份 | 当前文档、参数和引用的本地图片 | 每账户 100 个，每个 8MB |

完整备份恢复会先校验文件并显示数量，确认后创建新的作品、图片和版本标识。恢复副本不会覆盖原数据；重复恢复会生成另一份副本。

备份不包含登录凭据、服务密钥或之前下载的 PNG / JPEG。模板中自定义的外部图片 URL 仍依赖对应站点；使用本地素材才能得到自包含的图片资源备份。

### 4.9 可选云端账户与管理后台

账户模块提供登录、退出、手动上传备份、恢复副本和删除自己的云端备份。服务端按身份隔离数据，更新与删除时检查版本，防止陈旧操作覆盖已有备份。云端备份不会自动合并多个设备的修改。

管理后台提供用户与审计记录分页、概览计数、上传维护开关和公告。暂停上传后，用户仍可下载已有备份或使用本地功能。管理员权限由服务端身份配置决定；维护设置变更也有版本校验和审计记录。

云端模块的代码与本地测试已提供。真实登录、生产连接和跨设备流程仍需要部署并配置 Convex 与 OIDC 服务后联调。未配置时，页面显示“云端服务未启用”。

## 5. 典型使用流程

### 从模板制作一张图片

1. 在模板中心选择设计，创建作品。
2. 修改图层，或填写右侧模板参数。
3. 按需配置手机型号、时间、电量和状态栏。
4. 保存设计并检查导出预览。
5. 选择 PNG / JPEG、尺寸和相关选项，下载成品。

### 将参考图片变成可复用模板

1. 上传图片，选择智能重建或手动处理方式。
2. 校正识别文字，处理背景与图片区域。
3. 调整图层，为经常修改的内容添加参数。
4. 另存为自定义模板，以后复制使用或配置参数规则批量生成。

### 更换浏览器或设备

1. 在原浏览器导出完整备份，或在启用云端服务后手动上传作品备份。
2. 在新浏览器预览并恢复本地备份，或登录同一账户恢复云端副本。
3. 检查恢复结果后继续编辑。

## 6. 数据保存与当前边界

本地数据按浏览器和站点隔离。更换浏览器、切换站点地址或清理站点数据，都会影响原有本地作品的可见性；清理前应先备份。退出账户不会删除浏览器中的本地作品。

作品与历史、模板导入和备份恢复使用事务提交，失败时回滚相关写入。保存操作排队执行，避免较慢的预览生成覆盖后来的修改。

本站资源可由浏览器缓存，但应用尚无离线 Service Worker，不保证断网后仍能重新加载整个站点。当前也不提供公开分享链接、多人实时协作、后台自动同步或 AI 照片级修复；文件分享可通过导出模板或备份完成。

## 7. 实现与验收概况

前端使用 React、TypeScript、Vite 和 Fabric.js；本地存储使用 IndexedDB，OCR 使用 Tesseract.js。可选云端功能使用 Convex 和 OIDC 身份服务。

现有验收覆盖编辑、保存、导出、真实 OCR、参数规则批量生成、整库备份恢复、手机状态栏、移动端导航，以及本地模拟的权限、版本冲突、配额和审计逻辑。真实云端服务的验收需要相应部署与配置。

## 本次审查问题修复

- 本地保存新增独立的编辑修订号，与手动历史版本号分开。保存时在 IndexedDB 事务内比较修订号，并通过 BroadcastChannel 通知其他标签页。发生冲突时不覆盖原作，当前修改自动保存为独立的“冲突副本”，编辑器提供打开入口；继续留在旧编辑器的修改会更新该副本。通知不可用时仍由事务校验保护。
- 作品及历史删除、内部素材引用检查和清理在同一个事务内完成。新保存和新建作品同时校验素材存在，拒绝写入已删除的引用；仍被作品或历史使用的库素材不能强制删除。
- 自定义格式规则使用 RE2JS 线性匹配引擎，限制规则长度与校验输入长度。不支持的回溯引用、前后查找和无效规则明确提示错误，不再静默跳过；模板中原有规则文本保留，可在参数设置中修改。
- 透明 PNG 同时省略画布背景色和背景图片，普通前景图层继续渲染。文件下载与导出记录分开处理，记录失败不会再提示图片导出失败。
- 手机编辑器常驻保存、更多和导出入口，保存状态始终显示；其余操作移入更多菜单。手机主要按钮触控尺寸为 44px，图标按钮有可访问名称。
- 合法的手机时间、日期、运营商文字图层修改会同步回参数。调整画布时重新定位手机图层，同时保留手工内容和非几何属性；点击手机面板的“应用”仍按面板设置重新生成图层。
- 新输入的作品名称统一限制 200 个 UTF-16 码元，存储层也执行约束。已有长名称及备份恢复后附加后缀的名称继续完整备份恢复，不截断历史数据。
- 更新 Zod、body-parser、Undici、fast-uri 和 PostCSS selector parser，并通过锁文件固定实际解析版本。漏洞审计结果随公告变化，应持续在升级时复查。

## 批量状态栏随机

选择带手机状态栏的模板后，在批量做图的第 04 步开启“随机状态栏”。默认关闭，未启用的字段继续沿用模板。支持：

- 时间范围：精确到分钟，支持跨午夜；起止相同可固定时间。
- 日期范围：按真实日历日期随机，开启后同时显示日期，保留模板的日期格式。
- 电量范围：0–100 的整数，包含范围两端。
- 蜂窝信号、Wi-Fi 强度，以及从指定候选中抽取网络类型。
- 充电、飞行模式、蓝牙、定位、闹钟、静音、勿扰、VPN、HD、双卡及低电量状态：每个启用的状态以 50% 概率开启。

预览和 ZIP 导出使用同一批生成文档，点击“换一批”重新随机。随机过程不会修改原模板，也不改变正文参数的随机序列。机型、配色、时间格式及布局沿用模板；所有批量预览和成品均只包含屏幕内容，不包含硬件开孔。无状态栏的模板会提示先在编辑器添加。无效的范围会明确报错并禁止生成。
