# 海神作图：项目概念与功能说明

> 当前模板目录为 11 套、7 个分类。此前带“海神作图 · 设计示例”标识的 320 套内置模板已按用户要求下架；本文较早的扩充记录为历史说明，当前目录以[模板库说明](TEMPLATE_LIBRARY.zh-CN.md)为准。
更新日期：2026-10-26。本文描述当前功能；开发部署、具体机型和验证结果分别维护在对应文档中。

部署实施见[详细部署手册](DEPLOYMENT.zh-CN.md)。

## 1. 项目是什么

海神作图是一个本地优先的在线作图平台，帮助用户在浏览器里完成从参考图片、可编辑模板到成品图片的制作。

核心思路是：把设计拆成可编辑图层，把经常修改的内容设置为参数，再用同一套模板生成不同版本的图片。用户既可以直接修改文字、图片和样式，也可以像填写表单一样替换标题、价格、日期等内容，或设置参数规则批量生成图片。

平台适合宣传海报、社交配图、商品图、活动通知、节日祝福，以及手机界面展示图等场景。核心功能无需注册；账户与云端备份作为可选服务接入。

## 2. 产品原则

- **本地优先**：作品、模板、图片素材和历史版本默认保存在当前浏览器的 IndexedDB 中。
- **可编辑、可复用**：图层与参数是设计的基础，模板可以复制、修改、保存和再次使用。
- **操作可恢复**：支持撤销重做、历史版本、文件备份及恢复副本。
- **输出可验证**：根据设计数据重新渲染成品图片，导出质量不依赖编辑器当前的缩放比例。
- **服务状态明确**：未配置的云端功能显示“未启用”，操作失败时提供反馈。
- **资源由本站提供**：内置照片、展示字体与 OCR 引擎及模型随站点提供，常规本地流程无需请求第三方资源 CDN。

## 3. 几个核心概念

| 概念 | 含义 |
| --- | --- |
| 作品 | 一份正在制作或已经完成的设计，包含画布、图层、参数及相关设置 |
| 模板 | 可以重复使用的设计。用模板创建作品时会复制数据，后续各自编辑 |
| 图层 | 文字、图片、形状等独立元素，可调整位置、大小、样式、显示与锁定状态 |
| 参数 | 绑定到图层属性的可填写字段，例如标题、图片、颜色、字号、位置或日期文本 |
| 素材 | 存放在浏览器中的图片文件，可加入素材库或作为作品内部资源使用 |
| 历史版本 | 手动保存等操作产生的设计快照，可查看、备注、恢复或复制为新作品 |
| 云端备份 | 用户登录并手动上传的单个作品副本，用于后续下载到同一账户的其他浏览器 |

作品的文档数据是设计的主要记录。编辑器画布、预览、导出和备份围绕这份数据工作。

## 4. 主要功能

### 4.1 模板中心

顶部导航分为“模板”和“做图”：模板下有模板库、我的模板和上传生成模板；做图下有我的作品与批量做图。素材、备份、账户和帮助通过更多菜单进入。

提供具有真实图层数据的内置模板，支持分类浏览、收藏及创建新作品。新建作品时，内置照片会转为作品引用的本地素材，便于随模板文件和备份携带。

用户也可以把当前设计另存为自定义模板。修改自定义模板不会改动之前用它创建的作品。

### 4.2 上传图片与重建模板

支持上传 PNG、JPEG、WebP 图片，并提供三种处理方式：

| 方式 | 使用方式 |
| --- | --- |
| 智能重建 | 在浏览器中识别文字与位置，校正结果后生成可编辑文字图层及相关参数 |
| 原图背景 | 将参考图作为背景，在上面重建文字、添加图片框或遮罩 |
| 手动重建 | 以原色、不透明的锁定参考图层保留原图，可框选添加文字、图片及参数；需要从空白绘制时隐藏或删除参考层 |

图片中的文字由像素组成。OCR 可以提供文字内容与位置，用户仍需检查错字、漏字和排版结果。

背景修复使用本地算法，根据周围颜色填补旧文字区域，适用于纯色、渐变和简单纹理。复杂照片细节的还原能力有限；AI 照片级修复尚未接入。

手动框选使用透明虚线框，不会淡化原图。旧手动模板若存在平台生成的半透明原图参考层，编辑器提供“恢复原图清晰度”，仅修复该参考层且支持撤销，不修改手工设置的其他透明度。清晰度设置同时用于编辑、预览和导出。

### 4.3 图层编辑器

支持文字、图片、形状和背景编辑，以及图层排序、选择、对齐、组合、锁定、隐藏和复制。文字可调整字体、字号、颜色等属性；图片支持替换、适配和裁剪焦点等设置。

编辑器提供撤销重做、自动保存、手动保存、历史版本及预览。移动端保留保存、更多和导出入口，持续显示保存状态；其余工具通过菜单或面板访问。调整画布尺寸时，可以选择智能适配、等比缩放或保留元素位置与尺寸；手机状态栏会按新的画布尺寸重新贴合。

### 4.4 参数化设计

支持文字、多行文本、数字、日期、图片、颜色、字体、字号、选项、开关，以及尺寸、位置、旋转、透明度等参数类型。

参数名称可自定义：点击参数名称旁的铅笔直接重命名，Enter 保存、Esc 取消，也可通过齿轮设置修改。新名称去除首尾空格、不能为空，最多 80 个 UTF-16 码元；旧数据中的较长名称保持兼容。改名不改变参数标识、图层绑定、填写值、默认值及规则，支持撤销重做，随模板文件和备份保存，并用于作图表单与批量规则。作品是模板的副本，修改模板不会追溯改名已有作品。

参数可以设置分组、说明、默认值、必填条件和校验规则。例如，为商品图设置“商品名”“价格”“主图”参数后，用户可以直接填入新内容，继续沿用原来的排版。自定义格式规则使用 RE2JS 线性匹配引擎；无效规则、不支持的回溯引用和前后查找会明确报错。

### 4.5 手机机型与状态栏

新增自然布局及自动融合：按原图匹配纯色或简单纵向渐变、自动明暗配色，复杂背景保留并提示检查；支持 9 个系统版本参考、手动设置锁定、原图／效果局部放大。新设置默认开启，旧作品保留旧版外观，主动开启才升级。详见[自然融合指南](STATUS_BAR_FUSION.zh-CN.md)。

在编辑器的“手机”工具中选择机型，配置手机屏幕展示图所需的信息。桌面端入口位于左侧工具栏，手机端入口位于底部工具栏。

提供按品牌分组的 62 个具体型号，其中安卓及鸿蒙机型 51 个，涵盖 Samsung、Google、小米、Redmi、华为、荣耀、OPPO、一加、vivo、iQOO 和 realme。完整型号、参考分辨率及系统样式见 [手机机型目录](PHONE_MODELS.zh-CN.md)。

模板制作页面不再设置状态栏。模板编辑器通过“进入作图”复制当前内容为新作品，再配置品牌与型号、顶栏配色、覆盖高度。批量作图可对普通模板直接设置手机效果。

可以调整：

- 时间及 24 / 12 小时格式，也可一次填入设备当前时间。
- 日期、中文月日、星期或 `YYYY-MM-DD` 格式。
- 0–100% 电量、百分比显示和充电状态。
- 蜂窝信号、Wi-Fi 强度、4G / 5G / LTE、飞行模式和蓝牙图标。
- 运营商名称及显示开关。
- 深浅图标配色、自定义颜色、背景颜色、透明背景、大小和位置、开孔展示及底部手势条。
- 低电量模式、电池样式、双卡、定位、闹钟、静音、勿扰、VPN 和 HD 图标。

选择机型立即切换状态栏，默认保留当前画布。需要改变分辨率时，勾选“同时适配机型画布尺寸”，切换机型或点击重新应用。设置支持保存、撤销、历史版本和备份。

机型预设用于设计参考，不读取手机的真实系统状态。系统版本、地区、主题和显示缩放会影响实际外观，未宣称所有真机像素级一致。生成图层默认锁定，可在图层面板解锁。合法的时间、日期和运营商文字修改会同步回手机参数；调整画布时保留手工内容及非几何属性。重新应用设置会重建并置顶这些图层；添加状态栏模式移除后恢复原正文位置与高度；不撤销用户另行调整的画布尺寸。

**保存图片时仅导出屏幕内容。** 时间、电量、日期等状态栏信息与底部手势条会保留；灵动岛、刘海、摄像头开孔等硬件装饰不进入成品图片。此规则适用于 PNG、JPEG、批量导出和导出预览。编辑器与模板备份继续保留原来的开孔设置，方便再次编辑。

### 4.5.1 APP 通知图标

单张作图手机面板与批量作图提供 APP 图标设置。内置快手、抖音、微信、QQ 等 28 种图标，支持中英文搜索和滚动选择；也可以上传 PNG、JPEG 或 WebP 自定义图标。

新增图标包括小红书、淘宝、美团、知乎、豆瓣、百度、网易云音乐、钉钉、阿里旺旺，以及 WhatsApp、Instagram、Facebook、Messenger、YouTube、Spotify、Discord、LINE、X、Zoom 和 Snapchat。

- 最多添加 8 个，支持显示 / 隐藏、排序、删除、大小和间距调整。
- 图标放在时间旁；空间不足时自动缩小并为时钟、开孔及右侧系统图标保留空间。
- 内置图标随状态栏颜色显示，自定义图标保留原色与透明度。
- 自定义图片不超过 2MB、1024×1024，按比例居中转换为 128×128 PNG，仅存于浏览器本地。
- 图标及素材引用随作品、历史、模板文件和备份保留；恢复时重建引用，隐藏图标也可再次显示。
- 批量做图支持固定 APP＋指定候选随机、随机增加数量区间、顺序及自定义上传，按候选型号最小共同容量校验。

通知图标属于可选的设计元素，部分系统的原生状态栏并不以此方式显示普通 APP 图标。保存图片时仍只输出屏幕内容。

### 4.6 批量生成

从模板库或已保存的参数化模板开始，设置生成张数及每个参数的规则：沿用模板、固定值、随机区间、随机时间段、候选值随机或自动编号。生成前显示参数校验和预览。

每组有效参数可生成一张 PNG，最终打包为 ZIP 下载。当前单次最多生成 200 张；失败项会明确列出，不计为成功生成。手机效果独立于内容模板，支持保留、覆盖与添加三种方式，可固定或随机具体型号和 APP。

### 4.6.1 状态栏独立随机

选择任意内容模板，在第 04 步配置固定手机设置，再按需开启型号、APP 或状态参数随机。未启用的字段使用固定设置。支持：

- 时间范围：精确到分钟，支持跨午夜；起止相同可固定时间。
- 日期范围：按真实日历日期随机，开启后同时显示日期，保留模板的日期格式。
- 电量范围：0–100 的整数，包含范围两端。
- 蜂窝信号、Wi-Fi 强度，以及从指定候选中抽取网络类型。
- 充电、飞行模式、蓝牙、定位、闹钟、静音、勿扰、VPN、HD、双卡及低电量状态：每个启用的状态以 50% 概率开启。

预览和 ZIP 导出使用同一批生成文档，修改规则后需重新生成预览，导出不重抽。型号候选可独立随机或均衡分配；APP 可固定＋随机并指定数量区间。支持逐张重抽，均衡模式保留该张型号。作图预设保存完整规则与自定义图标引用，并纳入完整备份。不会修改原模板，成品仅包含屏幕内容。详见[作图与批量随机指南](BATCH_DRAWING.zh-CN.md)。


### 4.7 作品、素材和版本管理

“我的作品”集中展示编辑项目与自定义模板，支持搜索、收藏、重命名、复制、继续编辑、查看历史、删除和模板文件导入导出。

素材库支持图片预览、名称与分类管理；仍被作品或历史使用的素材不能强制删除，引用检查与删除在事务中协调。历史版本可以添加备注、恢复或复制为新作品。导出记录保存文件名、格式、尺寸和来源信息，已下载的成品图片文件由用户自行保管。图片已生成但导出记录保存失败时，会提示记录未保存，不会将图片下载误报为导出失败。透明 PNG 同时省略画布背景色和背景图，保留前景图层。

### 4.8 备份与恢复

| 方式 | 内容 | 当前上限 |
| --- | --- | --- |
| 单个模板文件 | 当前文档、参数和引用的本地图片 | 80MB |
| 完整本地备份 | 作品与模板、保留的历史版本、素材库、导出记录、作图预设及内置模板收藏 | 100MB |
| 云端单个作品备份 | 当前文档、参数和引用的本地图片 | 每账户 100 个，每个 8MB |

完整备份恢复会先校验文件并显示数量，确认后创建新的作品、图片和版本标识。恢复副本不会覆盖原数据；重复恢复会生成另一份副本。

备份不包含登录凭据、服务密钥或之前下载的 PNG / JPEG。模板中自定义的外部图片 URL 仍依赖对应站点；使用本地素材才能得到自包含的图片资源备份。

### 4.9 可选云端账户与管理后台

账户模块提供登录、退出、手动上传备份、恢复副本和删除自己的云端备份。服务端按身份隔离数据，更新与删除时检查版本，防止陈旧操作覆盖已有备份。云端备份不会自动合并多个设备的修改。

管理后台提供用户与审计记录分页、概览计数、上传维护开关和公告。暂停上传后，用户仍可下载已有备份或使用本地功能。管理员权限由服务端身份配置决定；维护设置变更也有版本校验和审计记录。

云端模块的代码与本地测试已提供。真实登录、生产连接和跨设备流程仍需要部署并配置 Convex 与 OIDC 服务后联调。未配置时，页面显示“云端服务未启用”。

## 5. 典型使用流程

### 从模板制作一张图片

1. 在模板中心选择设计，创建作品。
2. 修改图层，或填写右侧模板参数。
3. 按需配置手机型号、时间、电量和状态栏。
4. 保存设计并检查导出预览。
5. 选择 PNG / JPEG、尺寸和相关选项，下载成品。

### 将参考图片变成可复用模板

1. 上传图片，选择原图、等比适配或自定义画布尺寸。
2. 选择 OCR、原图背景或手动重建；识别后校正文字，处理背景与图片区域。
3. 在模板编辑器调整正文图层、添加内容参数并保存。
4. 点击“进入作图”复制为作品，再设置手机效果与覆盖高度。

### 批量制作含随机状态栏的图片

1. 选择保存好的模板，设置生成张数和正文参数规则。
2. 在“手机效果与随机规则”中选择处理方式、型号候选、APP 与状态参数随机；不需要随机的字段使用固定设置。
3. 检查前几张预览及状态摘要，需要新结果时点击“换一批”。
4. 修正无效范围后生成，下载包含 PNG 的 ZIP。生成过程不改动原模板。

### 更换浏览器或设备

1. 在原浏览器导出完整备份，或在启用云端服务后手动上传作品备份。
2. 在新浏览器预览并恢复本地备份，或登录同一账户恢复云端副本。
3. 检查恢复结果后继续编辑。

## 6. 数据保存与当前边界

本地数据按浏览器和站点隔离。更换浏览器、切换站点地址或清理站点数据，都会影响原有本地作品的可见性；清理前应先备份。退出账户不会删除浏览器中的本地作品。

作品与历史、模板导入和备份恢复使用事务提交，失败时回滚相关写入。保存操作排队执行，避免较慢的预览生成覆盖后来的修改。

跨标签页编辑使用独立修订号校验和变更通知。旧标签页保存发生冲突时，当前修改自动另存为“冲突副本”，提供打开入口，不覆盖另一标签页的新修改。作品删除、历史删除及素材清理协调引用关系，拒绝保存已经删除的素材引用。

新输入的作品名称限制为 200 个 UTF-16 码元；已有长名称及恢复后附加后缀的名称继续完整备份恢复。历史工程目录、存储键和内部文件标识保留兼容，新导出模板和备份使用 `.haishen.json`、`.haishen-backup.json`。

本站资源可由浏览器缓存，但应用尚无离线 Service Worker，不保证断网后仍能重新加载整个站点。当前也不提供公开分享链接、多人实时协作、后台自动同步或 AI 照片级修复；文件分享可通过导出模板或备份完成。

## 7. 实现与验收概况

前端使用 React、TypeScript、Vite 和 Fabric.js；本地存储使用 IndexedDB，OCR 使用 Tesseract.js。可选云端功能使用 Convex 和 OIDC 身份服务。

现有验收覆盖编辑、保存、导出、真实 OCR、参数规则批量生成、整库备份恢复、手机状态栏、移动端导航，以及本地模拟的权限、版本冲突、配额和审计逻辑。真实云端服务的验收需要相应部署与配置。
