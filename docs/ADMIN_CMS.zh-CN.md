# 管理后台使用指南

[返回首页](../README.md) · [首次启用与部署](DEPLOYMENT.zh-CN.md) · [开发验证](DEVELOPMENT.zh-CN.md)

后台入口为 `/admin`，管理员登录只用于后台操作，访客浏览和本地作图仍免登录。首次启用所需 D1、R2、绑定与密码摘要统一见部署指南。

## 1. 分类管理

后台“分类管理”支持新增、改名、排序、显示／隐藏和删除空分类。数字越小越靠前。隐藏分类会同时隐藏前台该分类的模板。

仍有上传模板时，应先将模板移至其他分类或删除模板，再删除空分类。有内置模板的分类可以改名、排序和隐藏，不能直接删除。内置模板仍保留在程序中；后台上传模板单独管理。

“惠民十五五”默认是空分类，可以直接选择它管理后续内容。不会自动读取 GitHub 根目录上传文件，也不会自动发布草稿。

## 2. 上传、编辑和发布模板

1. 在前台模板制作页面完成设计与参数设置，导出包含图片的 `.haishen.json`／JSON 模板文件。
2. 在后台“模板管理”选择文件，浏览器生成真实预览，填写名称和所属分类。
3. 点击“上传为草稿”。草稿只在后台可见，访客无法读取文件。
4. 检查预览后点击“发布”。可编辑名称、分类、说明、标签、排序及发布状态。
5. 下架后，新的公开文件读取会被拒绝。用户此前创建的个人作品已经保存了自己的图片副本，不会被删除。

当前单个模板文件上限 20MB，最多 200 张 PNG／JPEG／WebP 图片，单张图片及画布最多 4000 万像素、单边最多 16000。外部图片 URL、SVG 和缺少图片数据的文件不能上传；先在编辑器中保存图片并导出完整文件。

共享目录最多保存 1000 套上传模板、100 个分类。预览图由浏览器生成 PNG，最多 2MB，边长不超过 2048；不需要管理员另外制作封面。

前台模板库和首页读取已发布共享模板，批量页面也能选择。第一次使用时将模板中的图片导入当前浏览器，之后个人作品可独立编辑、保存、备份和导出。前台刷新可立即读取改动，已打开页面会定期刷新公开目录。共享模板读取失败会明确报错，不会生成虚假的成功结果。

## 3. 前台模板投稿与后台审核

前台入口 `/submit`，模板库顶部和“更多”菜单均有“提交模板”。无需账号，选择编辑器导出的完整 JSON 模板，填写名称、分类、说明和可选标签；提交者称呼、联系方式及给管理员的备注可选，只有管理员可见。浏览器生成实际预览，成功收到服务端回执后显示提交编号。

后台进入“投稿审核”，按待审核、已通过、已拒绝或全部筛选。查看详情会重新读取受保护的完整模板并生成实际画面，展示尺寸、参数名称／类型／默认值／规则和提交资料。管理员可在发布前调整名称、分类、说明及标签，点击“审核并发布”；也可填写拒绝备注后拒绝。拒绝仅记录到后台，不发送邮件或自动通知。删除投稿会删除其模板记录和文件；已通过投稿若删除，也会移除已发布模板，操作前有确认提示。

待审核和已拒绝模板不进入公开目录，访客不能读取其文件；不能从普通模板管理接口绕过审核直接发布。已通过模板进入正常模板管理，可下架、修改或删除。访客创建的本地独立副本不随下架或删除消失。

使用现有 D1、R2 和管理员机密，无需新增绑定。原 CMS 已初始化后，首次访问投稿接口或管理员目录会自动补建 `cms_submissions` 及索引，之后只检查已有索引，不重复执行建表。迁移脚本备份位于 `migrations/catalog/0002_submissions.sql`，可重复执行。CMS 未配置完成时，前台明确显示提交服务未启用。

模板上限仍为 20MB，图片格式与完整性校验和后台上传一致。每个来源每小时最多 5 次提交尝试，全站每 24 小时最多 100 次；待审核及已拒绝的累计队列上限 200 条，总模板上限 1000 套。管理员发布或删除可释放未处理队列容量。上传使用提交编号进行幂等处理，同一份未修改表单的网络重试不会重复创建投稿。审核与删除检查修订号，避免多人重复处理；操作写入审计记录。

## 4. 弹窗设置

后台“弹窗设置”支持：是否启用、标题、正文、点击按钮或输入指定文字、按钮文字、确认文字，以及同一标签页一次／每次打开页面。

正文按纯文本显示并保留换行，不执行 HTML。确认文字是公开访问提示，不是管理员密码。后台入口不受前台弹窗影响。

保存后在访客新打开或刷新的页面生效，不中途卸载已打开的编辑器。弹窗版本更新后，“同一标签页一次”会对新版本重新确认。关闭弹窗后访客直接进入，无需注册或登录。

未保存云端弹窗设置时，保留现有欢迎提示行为。

## 5. 权限、冲突与备份

管理员会话最长 4 小时，使用 HttpOnly Cookie；写入还检查同源与 CSRF。密码尝试超过限制时按来源暂时限制登录。保存带版本校验，冲突时保留输入并提示刷新，不用旧数据覆盖新数据。后台可查看最近 100 条成功管理操作。

网站更新不会自动清除 D1 和 R2。GitHub 只保存程序和迁移脚本，**不自动备份后台上传的模板与设置**；应同时备份 D1 与 R2，或在需要时下载已发布模板文件。个人作品的浏览器备份仍按原功能使用。

删除共享模板会移除目录记录，并清理私有文件；清理暂时失败的任务会在后续后台访问时重试。文件公开访问始终核对数据库中的发布状态。


## 6. 账号与密码

后台可修改密码：填写当前密码与至少 12 字符的新密码。保存后旧会话失效，重新登录即可，无需部署。忘记密码时按照[部署指南](DEPLOYMENT.zh-CN.md#7-重新部署并验证)更新管理员摘要。不要共享管理员密码。

## 7. 常见问题

- 后台显示未启用：先检查部署指南中的资源绑定、机密和数据库初始化。
- 发布失败提示分类隐藏：先将目标分类设为前台可见。
- 模板图片或引用缺失：重新导出“模板文件（含图片）”，不要上传只有浏览器素材 ID 的裸文档。
- 页面改动未生效：确认保存成功；弹窗设置在访客刷新或新打开页面后生效。
