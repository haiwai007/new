# Cloudflare 分类、模板与弹窗后台

更新：2026-10-28。

后台地址：`https://new-35o.pages.dev/admin`。前台仍免登录，管理员登录只用于后台写入。共享分类与设置保存在 D1，模板文件和预览图保存在私有 R2 存储桶；浏览器中的个人作品继续使用 IndexedDB。

代码部署后，如果资源没有绑定，后台会显示“后台服务尚未启用”，不会模拟保存成功；前台继续使用内置模板。**正式启用必须完成以下资源绑定、迁移和密码配置。**

## 1. 创建 D1 数据库

在 Cloudflare 控制台打开“存储和数据库 → D1”，新建数据库，例如 `haishen-catalog`。名称可以自行调整，记下所选数据库。

初始化有两种方式：

- 控制台方式：打开该数据库的 SQL 控制台，把仓库 [migrations/catalog/0001_initial.sql](../migrations/catalog/0001_initial.sql) 中的 SQL 语句执行一次。若控制台每次只接受一条语句，按分号分隔依次执行。不要删除已有表；脚本使用 `IF NOT EXISTS` 与 `INSERT OR IGNORE`，可重新执行。
- 命令行方式：在仓库根目录执行以下命令。此时 Wrangler 会通过你自己的浏览器登录 Cloudflare；聊天中不需要提供账号密码或 API Token。

```bash
pnpm exec wrangler login
pnpm exec wrangler d1 execute haishen-catalog --remote --file=migrations/catalog/0001_initial.sql
```

如果数据库不是 `haishen-catalog`，替换命令中的名称。初始化将创建分类、模板、弹窗设置、会话、登录尝试计数、操作记录及待清理文件表，并加入当前 8 个分类，包括“惠民十五五”。不会导入仓库 `模版/` 下的三个文件。

## 2. 创建 R2 存储桶

打开“存储和数据库 → R2”，创建存储桶，例如 `haishen-template-files`。保持存储桶私有，不启用公开 `r2.dev` 地址，也不绑定公开文件域名。文件通过项目 API 读取，草稿必须登录后台才能访问；发布后访客可匿名读取。

若账号尚未开通 R2，需要先按 Cloudflare 控制台提示完成开通。实际额度和费用由 Cloudflare 账号的套餐、用量决定。

## 3. 给 Pages 项目绑定资源

打开“Workers 和 Pages → new → 设置 → 绑定”，为生产环境添加：

| 绑定类型 | 变量名称（必须一致） | 选择资源 |
| --- | --- | --- |
| D1 数据库 | `CATALOG_DB` | 第 1 步创建的数据库 |
| R2 存储桶 | `CATALOG_FILES` | 第 2 步创建的存储桶 |

如需预览部署也能管理，给预览环境绑定单独的测试资源，避免预览环境改动生产数据。绑定名称区分大小写。

本项目的 Pages Functions 位于仓库根目录 `functions/`，API 路由为 `/api/*`。Pages 项目的根目录应为仓库根目录，构建命令继续使用 `pnpm build:studio`，输出目录继续使用 `artifacts/caishen-studio/dist/public`。不要把根目录改成 `functions` 或前端源码目录。

可选的 Wrangler 配置示例见 [deploy/wrangler.cms.example.jsonc](../deploy/wrangler.cms.example.jsonc)。这是手动命令行部署的参考，不会用占位数据库 ID 覆盖你的控制台绑定。

## 4. 设置管理员账号与密码

后台没有默认密码。可选账号变量为 `ADMIN_USERNAME`，未设置时账号为 `admin`。

在自己的电脑下载或克隆本仓库，安装 Node.js 24，然后在仓库根目录执行：

```bash
node scripts/create-admin-password.mjs
```

输入自己选择的 12～256 字符密码，终端不回显密码。程序只输出一行摘要，格式类似：

```text
pbkdf2$100000$32位随机盐$64位摘要
```

上面是格式说明，不能直接作为实际摘要使用。复制程序生成的完整一行，在 Pages 项目“设置 → 变量和机密”中添加：

| 名称 | 类型 | 值 |
| --- | --- | --- |
| `ADMIN_PASSWORD_HASH` | 机密／加密变量 | 生成的完整摘要 |
| `ADMIN_USERNAME` | 文本变量，可选 | 管理员账号，例如 `admin` |

不要把这些值放入 `VITE_*` 变量，也不要把真实密码或摘要提交到 GitHub。进入后台时输入原密码，不是摘要。正常登录后，在后台“修改密码”中输入当前密码和新密码即可，不需要重新部署；新密码至少 12 个字符，修改后所有后台会话失效，需要重新登录。新密码摘要仅保存在 D1，不通过目录接口返回。

如确需使用 6 位临时初始密码，可运行 `node scripts/create-admin-password.mjs --initial`，生成摘要后仍放入上述机密变量；登录后通过“修改密码”更换。程序不内置默认密码，仓库也不保存实际初始密码或摘要。

忘记密码时，可重新生成摘要、更新 `ADMIN_PASSWORD_HASH` 机密并重新部署；新的部署摘要会重置后台密码并使旧会话失效。日常网站部署不会重置已在后台修改的密码。

如已通过 Wrangler 登录自己的 Cloudflare 账号，也可执行：

```bash
pnpm exec wrangler pages secret put ADMIN_PASSWORD_HASH --project-name new
```

按提示粘贴摘要。这样避免在命令行参数中展开 `$` 字符。

## 5. 重新部署并核对

资源绑定和变量变更后，在 Pages 的部署页面重新部署最新 `main` 提交。首次绑定需要这次重新部署；后台正常启用后，日常改分类、发布模板和改弹窗不需要重新构建网站。

打开 `/admin`，应显示管理员登录表单。若仍显示未启用，页面会列出缺失绑定或数据库初始化提示。

还可以直接查看：

- `/api/admin/status`：应包含 `enabled: true`、`migrated: true`、`missing: []`。
- `/api/public/catalog`：访客不登录也应返回 `enabled: true` 和公开目录。
- 未登录访问 `/api/admin/catalog`：应返回 401，这是权限保护正常的表现。

**不要对整个 Pages 项目开启 Cloudflare Access 登录保护**，否则前台也会要求登录。本后台已经提供独立管理员登录；如额外使用 Access，应只保护 `/admin`、`/admin/*` 和 `/api/admin/*`，不要保护前台页面或 `/api/public/*`。

## 6. 分类管理

后台“分类管理”支持新增、改名、排序、显示／隐藏和删除空分类。数字越小越靠前。隐藏分类会同时隐藏前台该分类的模板。

仍有上传模板时，应先将模板移至其他分类或删除模板，再删除空分类。有内置模板的分类可以改名、排序和隐藏，不能直接删除。内置模板仍保留在程序中；后台上传模板单独管理。

“惠民十五五”默认是空分类，可以直接选择它管理后续内容。不会自动读取 GitHub 根目录上传文件，也不会自动发布草稿。

## 7. 上传、编辑和发布模板

1. 在前台模板制作页面完成设计与参数设置，导出包含图片的 `.haishen.json`／JSON 模板文件。
2. 在后台“模板管理”选择文件，浏览器生成真实预览，填写名称和所属分类。
3. 点击“上传为草稿”。草稿只在后台可见，访客无法读取文件。
4. 检查预览后点击“发布”。可编辑名称、分类、说明、标签、排序及发布状态。
5. 下架后，新的公开文件读取会被拒绝。用户此前创建的个人作品已经保存了自己的图片副本，不会被删除。

当前单个模板文件上限 20MB，最多 200 张 PNG／JPEG／WebP 图片，单张图片及画布最多 4000 万像素、单边最多 16000。外部图片 URL、SVG 和缺少图片数据的文件不能上传；先在编辑器中保存图片并导出完整文件。

共享目录最多保存 1000 套上传模板、100 个分类。预览图由浏览器生成 PNG，最多 2MB，边长不超过 2048；不需要管理员另外制作封面。

前台模板库和首页读取已发布共享模板，批量页面也能选择。第一次使用时将模板中的图片导入当前浏览器，之后个人作品可独立编辑、保存、备份和导出。前台刷新可立即读取改动，已打开页面会定期刷新公开目录。共享模板读取失败会明确报错，不会生成虚假的成功结果。

## 8. 前台模板投稿与后台审核

前台入口 `/submit`，模板库顶部和“更多”菜单均有“提交模板”。无需账号，选择编辑器导出的完整 JSON 模板，填写名称、分类、说明和可选标签；提交者称呼、联系方式及给管理员的备注可选，只有管理员可见。浏览器生成实际预览，成功收到服务端回执后显示提交编号。

后台进入“投稿审核”，按待审核、已通过、已拒绝或全部筛选。查看详情会重新读取受保护的完整模板并生成实际画面，展示尺寸、参数名称／类型／默认值／规则和提交资料。管理员可在发布前调整名称、分类、说明及标签，点击“审核并发布”；也可填写拒绝备注后拒绝。拒绝仅记录到后台，不发送邮件或自动通知。删除投稿会删除其模板记录和文件；已通过投稿若删除，也会移除已发布模板，操作前有确认提示。

待审核和已拒绝模板不进入公开目录，访客不能读取其文件；不能从普通模板管理接口绕过审核直接发布。已通过模板进入正常模板管理，可下架、修改或删除。访客创建的本地独立副本不随下架或删除消失。

使用现有 D1、R2 和管理员机密，无需新增绑定。原 CMS 已初始化后，首次访问投稿接口或管理员目录会自动补建 `cms_submissions` 及索引，之后只检查已有索引，不重复执行建表。迁移脚本备份位于 `migrations/catalog/0002_submissions.sql`，可重复执行。CMS 未配置完成时，前台明确显示提交服务未启用。

模板上限仍为 20MB，图片格式与完整性校验和后台上传一致。每个来源每小时最多 5 次提交尝试，全站每 24 小时最多 100 次；待审核及已拒绝的累计队列上限 200 条，总模板上限 1000 套。管理员发布或删除可释放未处理队列容量。上传使用提交编号进行幂等处理，同一份未修改表单的网络重试不会重复创建投稿。审核与删除检查修订号，避免多人重复处理；操作写入审计记录。

## 9. 弹窗设置

后台“弹窗设置”支持：是否启用、标题、正文、点击按钮或输入指定文字、按钮文字、确认文字，以及同一标签页一次／每次打开页面。

正文按纯文本显示并保留换行，不执行 HTML。确认文字是公开访问提示，不是管理员密码。后台入口不受前台弹窗影响。

保存后在访客新打开或刷新的页面生效，不中途卸载已打开的编辑器。弹窗版本更新后，“同一标签页一次”会对新版本重新确认。关闭弹窗后访客直接进入，无需注册或登录。

未保存云端弹窗设置时，保留现有欢迎提示行为。

## 10. 权限、冲突与备份

管理员会话最长 4 小时，使用 HttpOnly Cookie；写入还检查同源与 CSRF。密码尝试超过限制时按来源暂时限制登录。保存带版本校验，冲突时保留输入并提示刷新，不用旧数据覆盖新数据。后台可查看最近 100 条成功管理操作。

网站更新不会自动清除 D1 和 R2。GitHub 只保存程序和迁移脚本，**不自动备份后台上传的模板与设置**；应同时备份 D1 与 R2，或在需要时下载已发布模板文件。个人作品的浏览器备份仍按原功能使用。

删除共享模板会移除目录记录，并清理私有文件；清理暂时失败的任务会在后续后台访问时重试。文件公开访问始终核对数据库中的发布状态。

## 11. 本地验证

```bash
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test:studio
pnpm build:studio
CMS_E2E=1 E2E_PORT=5180 pnpm test:e2e cms.spec.ts cms-submissions.spec.ts
```

CMS 浏览器测试使用真实 Cloudflare Worker 本地运行时、D1 和 R2，测试账号只在测试进程内生成，不是生产默认账号。`workerd` 安装脚本已明确允许，版本随锁文件固定。

常见问题：

- `/api/*` 返回 HTML：Pages Functions 未部署，检查项目根目录和仓库 `functions/` 是否参与构建。
- 提示数据库尚未初始化：在已绑定的实际数据库执行迁移，而不是只在本地数据库执行。
- 登录后仍提示未授权：确认 HTTPS、Cookie 未被浏览器拦截、生产环境摘要设置正确；不要使用摘要作为登录密码。
- 发布失败提示分类隐藏：先将分类设为前台可见。
- 图片格式或引用缺失：重新导出包含图片的完整模板；不要直接上传仅有本地素材 ID 的裸文档。
