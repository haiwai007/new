## 制作模板

上传 PNG、JPEG 或 WebP，选择处理方式：

- **智能重建**：在浏览器本地识别文字，先检查识别结果，再生成可编辑内容。
- **原图背景**：保留图片，手动框选目标区域并添加参数。
- **手动重建**：保留清晰参考层，手动添加文字、图片和形状。

框选时只包含目标内容，可用放大镜、吸附与位置数值微调。选择文字、数字／金额、订单号、卡号、头像、Logo 或普通图片，设置易懂的参数名称。

需要替换旧内容时，选择适合的底图处理方式：保留底图、纯色覆盖或自定义替换底图。白色覆盖适用于白底，复杂背景需要单独修补。临时试填用于检查，正式默认值才会随模板保存；检查图片裁剪后可点击“设为默认值”。

多选参数框可进行六向对齐、等宽等高及等间距；可指定固定基准框，每次操作支持撤销。框的位置与框内文字对齐方式分别设置。

完整操作见[参数与框选指南](guides/TEMPLATE_PARAMETERS.zh-CN.md)。

## 使用模板作图

模板页点击“使用模板”进入统一作图工作台。原 `/batch` 链接继续可用。

1. 选择内置、自定义或已发布的共享模板。
2. 设置生成张数：1 张下载 PNG，多张打包 ZIP，最多 200 张。
3. 给每个参数选择沿用模板、固定、候选随机或适用的生成规则。
4. 按需设置手机效果，默认保留原图。
5. 生成预览、点击图片放大检查，再生成并下载。

编号继承位数、前后缀与星号格式；脱敏卡号支持多个固定卡头与随机尾号。金额可设小数位、前后缀和千位分隔。日期可选仅日期、到分钟或到秒。

修改规则后重新生成预览；导出使用当前预览，不再次抽取随机结果。具体选项见[作图与批量规则](guides/BATCH_DRAWING.zh-CN.md)。

## 手机状态栏

模板中只定位状态栏外框，可自动建议后手动调整，直接确认；型号、时间、电量和 APP 图标在作图时设置。替换限制在确认区域内，不改动框外内容。

选择“修改状态栏”后，各项可分别固定或随机。APP 图标支持国内／国外分类、搜索及自定义上传。复杂纹理背景仍需要人工检查，参考型号布局不代表每个系统版本已经真机核准。

## 模板库与投稿

内置目录包含海报、社交配图、商品图、活动通知、节日祝福、图文设计和空白画布；“惠民十五五”保留为独立分类。共享模板与分类由管理员维护。

模板库支持分类、搜索、收藏及预览。使用模板创建独立作品，不修改模板原件。后台下架共享模板不会删除已经保存的本地副本。

投稿步骤：

1. 在编辑器“更多”中导出**模板文件（含图片）**。
2. 打开“提交模板”，选择 `.haishen.json` 文件，检查实际预览。
3. 填写名称、分类和说明，按需填写称呼或备注，提交审核。
4. 收到提交编号后等待管理员审核；提交成功不代表已经公开发布。

投稿上限为 20MB，提交者联系方式与备注只对管理员可见。服务未启用时不能投稿，本地作图仍可使用。仓库 `模版/` 是用户原始文件，不会自动导入公开目录。

## 保存、备份与迁移

| 方式 | 内容 |
| --- | --- |
| 浏览器本地保存 | 当前浏览器、当前站点的作品、模板与素材 |
| `.haishen.json` | 单个模板／文档、参数及引用的本地图片，导入上限 80MB |
| `.haishen-backup.json` | 本地作品、历史、素材、导出记录等，导入上限 100MB |

旧格式继续兼容。备份恢复先校验和预览，再创建副本，不覆盖原记录。跨标签页保存冲突会提示处理，避免旧数据覆盖新修改。

清除浏览器站点数据会删除本地作品；更换浏览器、设备或域名前先备份。外部图片网址依赖来源站点，导入本地素材才能完整携带。已下载的图片不包含在完整备份中，网站也不保证断网后能重新打开。

## 常见问题

- **导出的图片包含手机外壳吗？** 不包含外壳、刘海或摄像头开孔，仅导出屏幕内容。
- **没有登录能用吗？** 本地作图和浏览公开模板无需登录，管理后台单独登录。
- **图像已下载，但记录失败？** 文件仍然有效；导出历史写入与图片下载分别处理。
- **网站更新会删掉作品吗？** 更新不主动清除本地数据；域名和浏览器数据变化则需要迁移。
- **上传按钮需要什么文件？** 可编辑模板投稿使用包含图片的模板 JSON，普通 PNG/JPG 仅用于制作底图或图片参数。
