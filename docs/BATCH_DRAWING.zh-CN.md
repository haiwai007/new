# 作图设置与批量随机使用说明

更新日期：2026-10-26。

## 1. 制作模板与作图分工

模板制作只处理图片、OCR、文字、图层、内容参数及画布，不再显示手机状态栏入口。模板编辑器顶部的“进入作图”将当前内容复制为新作品，再设置手机效果；不会修改模板原件。

单张作品左侧“手机”（移动端底部）设置固定型号、时间、日期、电量、网络、配色、APP 通知与覆盖高度。既有模板的手机图层和参数继续读取，进入作图时作为初始值。不会自动删除手工绘制的图层。

## 2. 状态栏处理方式

| 方式 | 行为 |
| --- | --- |
| 保留原图 | 不生成新状态栏；批量时保留模板当前画面，包括旧模板已有的状态栏 |
| 覆盖原图状态栏 | 在顶部覆盖生成，保持原画布尺寸；可调整颜色及原状态栏覆盖比例 |
| 添加状态栏 | 增加顶部区域，正文整体下移，不拉伸背景或正文；最终高度随状态栏占用增加 |

单张作图移除平台生成的状态栏时，添加模式会恢复原有正文位置与画布高度；覆盖模式不会撤销另行主动进行的画布尺寸修改。手工画进原图的状态栏像素不会凭空消失，应使用覆盖处理。

切换具体型号会使用对应品牌系统的参考样式。默认保持正文宽度和尺寸，不根据候选型号随机切换原生分辨率。添加模式会按具体状态栏实际高度增加画布，并在每张预览下显示最终尺寸；超过 8000px 会提示错误。

## 3. 指定手机型号随机

在批量第 04 步选择“覆盖”或“添加”，再设置“批量手机型号”：

- 固定型号：使用固定设置中的型号。
- 指定型号随机：按品牌筛选或搜索，勾选具体型号；支持全选当前筛选结果、清空。
- 独立随机：每张从候选中抽取，允许连续重复。
- 均衡分配：各候选出现次数最多相差一次，再打乱顺序；张数少于型号数时随机选择部分型号。

先确定型号，再应用系统布局、状态参数与 APP 图标。型号分配独立于正文参数和 APP 随机，不会因为改变 APP 候选而重新分配型号。

## 4. 固定与随机 APP 通知

| 模式 | 行为 |
| --- | --- |
| 沿用固定设置 | 使用固定面板中配置的 APP 图标，兼容旧模板 |
| 不显示 APP 图标 | 本批次不生成 APP 通知，不影响信号、电量等系统图标 |
| 固定图标 | 所选固定 APP 每张都出现 |
| 固定＋随机 | 固定 APP 每张出现，再从指定候选中不重复抽取 |

每个 APP 只能选一种用途，不可同时固定和随机。同一张内不重复；不同图片允许相同组合。固定列表可为空，此时为纯随机。

“随机增加最少/最多数量”仅计算随机部分，界面同时显示最终总数。例如固定微信，候选 QQ、抖音、快手，区间 0～2，则每张最终显示 1～3 个通知。

先在区间中等概率选择数量，再不重复选取候选。默认按固定列表、候选列表的设置顺序排列，可调整顺序或选择随机排列。未被抽到的 APP 不会混入结果。

支持 28 个内置图标及自定义 PNG/JPG/WebP。自定义上传最大 2MB、1024×1024，等比缩放并居中存储为 PNG，保留颜色与透明度。图标可搜索、只看已选，并在状态栏底色下预览。

明确选择固定/随机 APP 时，按所有候选型号中的最小共同容量校验；界面显示容量，不会为了通过校验悄悄丢弃图标。容量不足时减少数量、调整固定面板内图标大小和间距，或移除受限型号。沿用旧模板图标时保留旧版本的缩放适配行为。

## 5. 时间、电量等独立随机

“随机状态栏”开关管理时间、日期、电量、信号、Wi-Fi、网络及更多系统图标；与手机型号、APP 随机独立。未启用的字段使用固定面板值。

时间支持跨午夜；日期使用真实日历；电量范围为包含两端的 0～100 整数。附加状态图标以 50% 概率开关。Wi-Fi、飞行模式仍遵守相应显示逻辑，不保证所有网络文字同时可见。

## 6. 预览与导出

每批 1～200 张，按页查看每张结果，显示型号、时间、电量、网络、APP 名称及图片尺寸。

- 修改规则后提示“需要重新生成预览”，旧下载失效，确认新预览后才可导出。
- “换一批”重新生成整批内容参数和已开启的随机效果。
- “重新随机第 N 张”只替换该张，其他图片不变；均衡模式保留该张型号，只重新随机其他项目，重新分配型号请用“换一批”。
- ZIP 导出直接使用当前结果，不再抽签；预览和导出使用同一批文档。
- 上传、生成或导出期间锁定相关设置。规则无效的图片显示原因，不计入成功数量。
- 只导出屏幕内容，保留状态栏与手势条，不输出手机外壳、灵动岛、刘海或硬件开孔。

## 7. 保存作图预设与迁移

命名后“保存为新预设”，可保存固定设置、处理方式、型号候选、分配方式及全部状态栏/APP 随机规则。本地最多 100 个预设，可应用或删除；切换模板保留本次已配置的手机规则，并重新校验适配。

单张作图应用预设时使用固定设置与固定 APP，不执行随机部分；原预设保留完整随机规则，供批量使用。

预设存入当前浏览器 IndexedDB，完整备份包含预设及候选列表引用的自定义图标。恢复时创建新标识并重映射图片引用，不覆盖旧预设。使用中的预设图标受删除保护，删除作品不会误删预设仍引用的图标。

预设不随单作品模板文件自动携带，也不会自动跨设备同步；迁移整个工作环境使用“备份与恢复”。旧版程序不认识新预设和添加状态栏元数据，回滚前应导出完整备份，并避免用旧版再次保存新版作品。

## 8. 模板参数自定义名称

进入模板编辑器的“参数”面板，点击参数名称旁铅笔，输入“活动标题”“商品价格”等名称，点击对勾或按 Enter 保存；叉号或 Esc 取消。也可通过齿轮内的“参数名称”修改。新名称不能为空，最多 80 个 UTF-16 码元，并去除首尾空格。

保存模板后，新建作图与批量规则会显示该名称；修改的是字段标签，不会更改图上的文字、参数绑定或已有规则。支持撤销重做，导出的模板与完整备份保留名称。既有作品是独立副本，不随源模板自动改名。

## 9. 状态栏自然融合

新建手机设置默认启用自然融合，可选择系统参考版本并自动匹配顶部背景、明暗和比例。“自动判断”需先确认处理方式，不擅自增加画布。复杂背景提示人工检查，旧作品主动开启才升级。

批量“生成预览”先准备每张融合结果，显示适配进度；ZIP 使用已确认的结果，不在导出时重新分析。保留原图模式不重绘已有状态栏。手动调整有优先级，预设和完整备份保留这些规则。详见[自然融合指南](STATUS_BAR_FUSION.zh-CN.md)。
