# APP 图标分类与新增图标

内置 90 个离线通知图标：国内 48 个、国外 42 个。保留原有 60 个图标 ID，新增 30 个；旧模板、固定选择和随机候选无需迁移。

作图的图标面板提供“全部／国内／国外”，自定义上传和已选列表继续单独显示。批量作图候选列表还提供“自定义”，可叠加关键词搜索和“只看已选”。分类只过滤列表，不修改已选图标、顺序、数量区间、随机规则或已生成结果。清空关键词或切换分类即可恢复列表。

分类是帮助查找应用与服务的静态目录，不按当前访问地址或用户位置判断。面向海外的 Trip.com 携程国际版归国外，国内的 1688 归国内；上传的图标归自定义，不推测其地区。

新增：大众点评、WeGame、铁路 12306、中国国航、东方航空、南方航空、CSDN、掘金、Gitee 码云、GitCode、豆瓣阅读、DeepSeek、通义千问、海螺 AI、扣子、阿里云、人人、豆包、Kimi、文小言（文心一言）、讯飞星火、智谱清言、腾讯元宝、即梦 AI、可灵 AI、腾讯混元、阶跃星辰、百度智能云、腾讯云、百川智能。

这些是用于小尺寸通知展示的品牌图形，不宣称均为官方完整 APP 桌面图标。保留来源的彩色层与渐变；原本采用黑色标识的品牌不强制改色。展示、预览及导出均使用本地 SVG，不依赖外部图标 CDN。

来源：Simple Icons（CC0，通过现有 react-icons 5.7.0）及 Lobe Icons（MIT）。逐图来源、固定提交与哈希见 [sources.json](sources.json)，完整 MIT 许可证随应用发布。复现：`NODE_USE_ENV_PROXY=1 node scripts/expand-domestic-app-icons.mjs`，随后按仓库格式化规则运行 Prettier。
