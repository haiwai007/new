# APP 图标分类与常用国内应用

内置 140 个离线图标：国内 98 个、国外 42 个。本轮新增 50 个常用国内应用，保留此前所有图标 ID，旧模板、固定图标和随机候选无需迁移。

作图图标面板提供“全部／国内／国外”；批量候选还提供“自定义”，可叠加关键词和“只看已选”。切换分类不改变已选、顺序或随机数量。搜索“58”“唯品会”“vipshop”等即可找到相应图标。新增生活类应用排在此前扩展的技术／AI 类图标前面。

使用应用主版本，排除司机端、商家版和名字相似的其他产品。58 同城对应 App Store ID 480079300、包标识 com.taofang.iphone；唯品会对应 417200582、com.vipshop.iphone。应用名称可能随版本调整，例如饿了么现商店名称为淘宝闪购，列表保留常用旧名称方便搜索。

新增 50 个图标使用相应发布者的公开 App Store 品牌图片，保留配色，直接嵌入 SVG 数据 URL，无外部图标请求，也能随便携模板导出。通知小尺寸显示会按可见图形适配；不把位图宣称为矢量，不声称是手机系统原生通知图标的精确复刻。

出处与权利归属：新增发布者图片见 [popular-cn-sources.json](popular-cn-sources.json)，含应用 ID、包标识、发布者、原始页面／图标地址和 SHA-256。权利归相应发布者，不将这些图片标为 CC0／MIT。此前图形来源仍见 [sources.json](sources.json)：Simple Icons（CC0，经 react-icons）和 Lobe Icons（MIT）。完整说明随应用的 attributions 目录发布。

复现：`NODE_USE_ENV_PROXY=1 node scripts/build-popular-cn-icons.mjs` 按已保存清单下载并核对哈希；首次检索可运行 `collect-popular-cn-icons.mjs`，公开检索节流至每分钟不超过 20 次，失败或限流即停止。新增图标后在本地开发服务启动的情况下运行 `measure-app-icon-ink.mjs`，重建视觉边界，最后运行 Prettier。

分类是静态查找目录，不按用户位置判断；Trip.com 国际版归国外，携程旅行归国内。上传素材归自定义，不自动猜测其地区。
