# 状态栏自然融合与系统参考样式

更新日期：2026-10-26。

## 使用流程

模板制作继续只负责正文。单张作品进入“手机”面板，选型号后使用自然布局；批量在第 04 步配置处理方式、随机型号和状态参数，再点击“生成预览”。

新建手机设置默认启用自然融合。已有作品和已有预设缺少新字段时使用旧版布局，不会因升级自动改写图层。旧作品需要在手机面板主动开启“智能自然融合”才升级，可撤销。布局兼容选项也可切回旧版参考布局。

## 系统样式

提供 9 个可选择的参考样式：iOS 17、18、26，One UI 6、7，HarmonyOS 4、5，HyperOS 1、2。其他品牌继续使用现有 Pixel、MagicOS、ColorOS、OriginOS、realme UI 等系统参考。

“按型号选择”只选择默认参考，不识别图片或设备实际系统版本。iPhone 17 默认使用 iOS 26 参考，iPhone 16 默认使用 iOS 18；不展示这些机型不适用的较早 iOS 选项，Galaxy S25 也不提供 One UI 6。可选版本取决于型号与系统家族。

自然布局统一时间与系统图标的视觉中心、留白和比例；时间使用本地 Arial / 系统替代字体，中文附加文字使用已有自托管字体。不分发苹果或厂商私有字体。版本外形是可编辑参考，未逐台设备、所有地区和主题实测，不承诺像素级复刻。

## 背景自动分析

自动分析当前画面的顶部：

- 近似纯色：匹配背景色和明暗，选择黑色或白色状态信息。
- 平滑的纵向渐变：生成自包含的渐变背景，添加顶部区域时让新区域底色衔接原图顶部。
- 纹理、照片或复杂背景：优先保留原图，提示检查对比度与旧状态内容。

这里只支持可靠的简单背景延续；横向渐变、复杂纹理等可能被判为复杂背景，不会强行涂成白色。疑似旧状态栏是像素分布推测，不是 OCR 确认。复杂背景若存在旧时间、图标，仍可能需要调整覆盖高度、使用背景修复或改为添加区域，系统不会假装完成无痕处理。

只有较高可信度且背景足够简单时才自动扩大疑似旧状态栏的覆盖高度；低可信度结果提示确认，不额外扩大覆盖。对比度提示会考虑用户手动选择的颜色。

分析仅保存有限的颜色、置信度与背景特征，不把局部预览截图写入预设。来源或顶部内容变化后重新分析；正文下方的参数变化可复用顶部结果。

## 处理方式与确认

| 方式 | 行为 |
| --- | --- |
| 自动判断 | 先分析并展示建议，再由用户确认覆盖、添加或保留；批量未确认时禁止生成新状态栏结果 |
| 保留原图 | 不生成、不重绘现有状态栏；批量保留现有已绘制外观 |
| 覆盖原状态栏 | 保持画布尺寸，在顶部范围生成；可调整覆盖高度 |
| 添加顶部区域 | 增加画布高度，正文下移，不拉伸正文或改变原图裁剪焦点 |

不会在不明确时擅自增加画布或进行大范围覆盖。主体图片不会被整图淡化、模糊或渐隐。

## 手动设置优先

自动适配后仍可展开高级微调。手动修改图标颜色、背景、覆盖高度、大小或位置时，会锁定对应设置。随后改变时间、电量、APP 或重新计算背景时保留这些调整；切换型号也保留已锁定的位置和大小。

“重新自动适配”重新分析原图并尊重手动锁定；“恢复自动适配（清除手动锁定）”清除这些覆盖项，恢复自动策略。

时间、电量、Wi-Fi、飞行模式、百分比等继续使用对应显示规则。iPhone 添加 APP 通知、附加日期或特殊状态组合等会提示属于自定义效果，不标成默认真机显示。

## 局部预览与 APP

手机面板提供原图顶部和融合效果的局部预览，可切换查看；“放大检查顶部”打开细节窗口，支持 1～3 倍显示及横向滚动。覆盖与安全区域辅助线只存在于编辑预览，不进入 PNG、JPEG 或 ZIP。

自然布局按真实可用区域计算通知容量，不再依靠不断缩小图标容纳任意数量；超过容量时提示调整大小、间距、数量或候选型号。旧版布局保留原有缩放行为。

自定义通知图标可保留原色，或根据透明度染为当前状态栏颜色；单色模式推荐透明 PNG，上传的不透明底色也会参与染色。原素材不被修改，颜色处理随图层设置、模板文件及备份保存。

## 批量稳定性

先确定型号，再按当前图片和该型号的状态栏区域适配，随后应用随机状态及 APP 组合。支持原有独立随机和均衡分配，不因背景分析重抽正文或型号。

“生成预览”会准备每张自然融合结果并显示进度。ZIP 直接渲染已准备的文档，不在导出过程中再次自动分析或随机。未完成适配的新结果需要重新生成预览，单张重抽也先完成适配再替换当前张。

作图预设及完整备份包含系统样式、融合策略、手动锁定和分析摘要。恢复或更换图片后，必要时重新分析新的顶部。预览图不随预设保存；引用的自定义图标继续受到素材删除保护。
