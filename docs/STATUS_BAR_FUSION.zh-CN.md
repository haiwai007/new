# 状态栏自然融合与系统参考样式

更新日期：2026-10-26。

## 使用流程

自然布局的原位替换先在模板里定位，再在作图页面设置效果。上传原图后自动提出候选，允许手动框选外框、时间、APP、系统图标及保护区；框选后可直接确认使用，测试仅为可选预览。具体步骤、失效规则和备份行为见[模板状态栏定位指南](STATUS_BAR_LOCATION.zh-CN.md)。

单张作品与批量第 04 步复用确认的位置；临时修改不写回源模板。手机型号只决定系统参考样式，原位替换保持原图尺寸。不使用顶部留白另加第二套状态栏。没有原状态栏时保留原图，或明确选择顶部新增。

旧模板和预设缺少自然布局字段时继续使用旧版布局，不自动改写。主动选择自然布局进行原位替换时，需先确认定位。日期和运营商需要对应位置；不能通过开启附加文字扩大到导航或正文。

## 范围与尺寸

文字与图标跟随已确认的小区域大小，替换仅发生在这些区域中。定位外框不代表整条涂色范围，保护区与替换区域相交时保留原图，不拦截确认。图片等比缩放保持标准化位置；直接确认后，即使图片或比例变化也继续使用标准化坐标，可按需重新调整。

原图资源保留，测试结果不写入原图。预览与导出使用同一组图层；批量随机结果在生成预览后固定。未确认、失效或设置与生成图层不一致时不允许导出旧替换结果。

## 系统样式

提供 9 个可选择的参考样式：iOS 17、18、26，One UI 6、7，HarmonyOS 4、5，HyperOS 1、2。其他品牌继续使用现有 Pixel、MagicOS、ColorOS、OriginOS、realme UI 等系统参考。

“按型号选择”只选择默认参考，不识别图片或设备实际系统版本。iPhone 17 默认使用 iOS 26 参考，iPhone 16 默认使用 iOS 18；不展示这些机型不适用的较早 iOS 选项，Galaxy S25 也不提供 One UI 6。可选版本取决于型号与系统家族。

自然布局统一时间与系统图标的视觉中心、留白和比例；时间使用本地 Arial / 系统替代字体，中文附加文字使用已有自托管字体。不分发苹果或厂商私有字体。版本外形是可编辑参考，未逐台设备、所有地区和主题实测，不承诺像素级复刻。

## 背景自动分析

自动分析当前画面的顶部：

- 近似纯色：匹配背景色和明暗，选择黑色或白色状态信息。
- 平滑的纵向渐变：生成自包含的渐变背景，添加顶部区域时让新区域底色衔接原图顶部。
- 纹理、照片或复杂背景：优先保留原图，提示检查对比度与旧状态内容。

这里只支持可靠的简单背景延续；横向渐变、复杂纹理等可能被判为复杂背景，不会强行涂成白色。疑似旧状态栏是像素分布推测，不是 OCR 确认。复杂背景若存在旧时间、图标，需要调整定位小区域、使用背景修复或明确改为顶部新增，系统不会假装完成无痕处理。

背景颜色可信不代表覆盖范围可信；即使背景近似纯色，也不能扩大到未确认的区域。对比度提示会考虑用户手动选择的颜色。

分析仅保存有限的颜色、置信度与背景特征，不把局部预览截图写入预设。来源或顶部内容变化后重新分析；正文下方的参数变化可复用顶部结果。

## 处理方式与确认

| 方式                 | 行为                                                                       |
| -------------------- | -------------------------------------------------------------------------- |
| 自动判断（单张作图） | 分析仅提供建议；原位替换框选后直接确认，无需测试 |
| 保留原图             | 不生成、不重绘现有状态栏；批量保留现有已绘制外观                           |
| 覆盖原状态栏         | 保持画布尺寸，仅在已确认的小区域生成，保护区不变 |
| 添加顶部区域         | 增加画布高度，正文下移，不拉伸正文或改变原图裁剪焦点                       |

不会在不明确时擅自增加画布或进行大范围覆盖。主体图片不会被整图淡化、模糊或渐隐。

## 手动调整与局部预览

自然布局的原位替换通过“调整状态栏定位”修改几何位置，旧的覆盖比例和位置滑块不用于扩大已确认区域。调整后可直接再次保存，不需要测试批准。文字与 APP 自动缩小到所选区域，超出外框的部分由输出掩膜裁切。

定位窗口提供原图和测试效果切换，支持 1～3 倍放大、拖动与边界调整；辅助线不会进入 PNG、JPEG 或 ZIP。旧版布局及顶部新增仍保留原有兼容设置。

自定义 APP 可保留原色或按透明度染为当前状态栏颜色；不透明图标底色也参与单色处理。原素材不修改。直接确认的区域按 APP 数量自动缩放，最多 8 个。

iPhone 添加通知图标、附加日期或特殊状态组合属于自定义效果，不标成默认真机显示。

## 批量稳定性

先复用模板确认的位置，再确定型号参考样式，应用随机状态及 APP 组合。支持原有独立随机和均衡分配，不因背景分析重抽正文或型号。

“生成预览”会准备每张自然融合结果并显示进度。ZIP 直接渲染已准备的文档，不在导出过程中再次自动分析或随机。未完成适配的新结果需要重新生成预览，单张重抽也先完成适配再替换当前张。

作图预设及完整备份包含系统样式、融合策略、手动锁定和分析摘要。恢复或更换图片后，必要时重新分析新的顶部。预览图不随预设保存；引用的自定义图标继续受到素材删除保护。
