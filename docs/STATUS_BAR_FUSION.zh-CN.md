# 状态栏自动适配与原图融合

模板只框选外框，型号与系统版本决定内部布局，原图提供背景、明暗及可靠时的字形比例参考。作图与批量作图默认保留原图，选择“修改状态栏”后才替换。

## 型号与版本

现有 100 个具体型号分别维护独立布局记录，包含时间起点、左右留白、开孔避让、字高、图标高度和间距、APP 大小及附加行比例。每个型号的版本记录分别保存，不在缺失时回退品牌通用配置。

提供 28 套系统参考样式：iOS 经典／17／18／26；One UI 6／7／8；HarmonyOS 4／5／6；HyperOS 1／2／3；Android 14／15／16（Pixel）；MagicOS 8／9／10；ColorOS 14／15／16；OriginOS 4／5／6；realme UI 5／6／7。

系统图形素材可以复用。参考版本选择不表示特定地区设备一定已推送该系统。当前均为参考配置，不冒充逐台真机标定，详见 [核对表](DEVICE_LAYOUT_AUDIT.zh-CN.md)。

## 自动处理

1. 从原图中读取外框内及邻近边缘像素，不修改源文件。
2. 自动背景采用边缘颜色延展与渐变重建；也可手动指定纯色。
3. 简单背景且时钟字形清晰时，参考字高和垂直中心。没有可靠字形时使用所选型号自己的比例。
4. 按型号与版本布局时间、APP、蜂窝、Wi-Fi、电池及其他图标，全部限制在外框内。
5. 自动选择深浅系统图标；内置 APP 保留品牌配色，自定义 APP 默认保留上传颜色。
6. 将结果合成到原图，在外框外恢复原始 RGBA。

自动适配不扩大框选范围，不改变画布尺寸，不模糊整张原图。复杂照片被旧字遮住的原始纹理无法保证恢复，用户可调整背景和范围，不设识别成功或像素阈值确认门槛。

## 内容与微调

型号、时间、电量、APP 分别支持固定或随机；随机预览生成后固定，放大和导出不重新抽取。日期和运营商默认关闭，开启后也安排在外框内部。更多设置保留大小、位置、留白、配色与网络图标等选项。

飞行模式隐藏蜂窝信号、HD 与网络类型，Wi-Fi 可独立开启。低电量模式电量不超过 20%。新增顶部空间属于单独选择的方式，不会因框内空间不足自动启用。

## 型号布局覆盖问题修复

- 已确认的历史“手动内框”模板在自然替换时转入型号布局，保留外框、源图和背景配置，不再把所有型号固定在旧时间／图标槽位内。原模板对象不被原地修改；无需用户重新框选。
- 原图字高用于计算统一缩放参考，不再除以各型号自己的字号，避免不同型号字号在缩放计算中被抵消。外框较小时仍按边界安全缩小。
- 改选另一个型号时使用新型号的默认系统版本；保持同一型号时，用户手选的版本继续保留。固定与随机型号均经过同一切换逻辑。
- 已生成的预览继续保持固定。更新设置后重新生成预览，再导出新结果；保留原图模式不做替换。同系统、相同配置的部分机型本就可能相似，修复不把未核准参考配置标记为真机核准。
