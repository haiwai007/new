# 状态栏定位：只框外框，按具体型号排版

更新日期：2026-10-28。

## 操作

1. 在模板编辑器打开“状态栏定位 → 定位原状态栏”。
2. 自动建议或手动框选状态栏的完整外框。只调整外框，支持放大、拖动、边角调整、像素输入、撤销与重做。
3. 直接确认并保存模板。测试替换只是可选预览，不是保存前提；没有识别、空白或复杂背景确认拦截。
4. 在作图页面选择具体型号、系统参考版本、时间、电量与 APP。内部位置按该型号／版本的独立记录生成。

外框内的旧内容会整体替换，切勿包含导航标题、返回按钮或正文。原有内部小框和保护区不再参与新布局，界面也不再编辑这些小区域。旧模板继续沿用原外框，未设置新字段的旧记录也按外框模式渲染。

## 原图适配

- 纯色背景自动匹配；自动背景还会从外框边缘采样，生成仅限框内的渐变／边缘延展补片。
- 仅在背景足够简单且字形清晰时，参考原时钟的字高和垂直中心；不可靠时使用该型号独立参考尺寸，不虚构识别成功。
- 时间、系统图标、APP、日期和运营商都在框内协调缩放。数量过多时缩小间距和内容，不扩大外框或静默删除 APP。
- 可以手动选择纯色背景、明暗、整体大小、上下位置与留白。
- 复杂照片中被旧字遮住的真实细节无法从单张图中保证恢复。边缘延展不等于原始纹理复原，不称为无痕 AI 修复。

## 像素边界与导出

外框采用标准化坐标，不改变画布尺寸。像素合成在外框之外恢复原始 RGBA，包含小数坐标、缩略预览和 2×／3×导出。外框模式不在底部额外绘制手势条，不向框外添加开孔或其他装饰。

预览、放大查看、保存、单张 PNG 和批量 ZIP 复用同一份固定结果，不重新随机。框选和型号设置在作图副本中变更时不改写源模板。模板文件、历史与备份保存外框、背景补片及源图适配信息。

## 独立布局与核对状态

提供 100 个具体型号的独立配置，以及各型号可选择的系统参考版本记录，共 28 套系统样式。运行时没有未知型号或缺失版本的品牌通用回退。

当前配置为参考适配，尚未经逐台、逐版本真机截图标定，不标记为真机核准。型号、参考尺寸、版本记录和状态见 [逐型号核对表](DEVICE_LAYOUT_AUDIT.zh-CN.md)。
