# 模板状态栏定位与安全替换

更新日期：2026-10-26。

## 先定位，后设置效果

模板负责标记原状态栏的位置，作图页面负责型号、时间、电量、网络和 APP；批量页面负责固定与随机规则。位置与效果分开保存。

1. 上传图片并进入模板编辑器。系统对带原图的模板尝试自动框选，结果标为“待确认”，不会直接修改原图。
2. 打开左侧 **状态栏定位**，点击 **定位原状态栏**。检查自动候选；找不到可靠候选时使用 **手动框选**。
3. 分别检查外框、时间、APP、系统图标。使用区域选择器切换目标，拖动边框或八个控制点；也可直接输入画布像素坐标。支持撤销、重做及原图放大。
4. 标记标题、胶囊按钮、摄像头附近内容等需要保留的 **保护区**。保护区不能与替换区域重叠。图片始终保持原亮度，不以白色蒙层突出选区。
5. 点击 **测试替换**，切换查看原图与测试效果。通过像素检查后，点击 **确认并保存定位**，再保存模板。
6. 在单张作图或批量第 04 步启用修改状态栏，设置固定或随机内容，生成预览并导出。型号只决定系统样式，不移动已确认的位置，也不改变模板图片尺寸。

模板没有状态栏且无需添加时，选择 **不设置状态栏**，继续使用原图。确实需要额外增加一行时，在作图设置中明确选择 **顶部新增**；该操作会下移原内容并增加图片高度。

## 替换范围

外框限制整个定位范围，真正清除旧内容的范围是时间、APP、系统图标及显式添加的日期、运营商小区域。外框内的其他内容也不会整条涂白。

时间和系统区域必须包含原有前景，不能只框选原状态栏上方的空白来添加第二套。各内容区域必须位于外框内，彼此不能重叠，不能覆盖保护区。框内仍有未指定的旧内容时，测试会提示调整或标为保护区。

日期、运营商需要额外标记对应区域后才能开启。没有相应区域会停止生成并提示处理，不会挤入标题或正文。APP 数量同时受候选数量、区域宽度、图标尺寸和间距限制；超出时提示调整，不会挤出区域。

简单背景自动采样纯色或纵向渐变，按小区域清除旧内容。复杂纹理无法可靠恢复时停止确认；可缩小区域、先修复背景，或明确选择手动纯色并重新测试。原图像素不包含被旧字挡住的背景，不能保证任意复杂照片背景都能无损补全。

预览与导出会按实际输出分辨率生成像素掩膜，强制保留内容小区域之外及保护区的原始 RGBA；小数坐标、缩略预览、2×／3×导出使用同一规则，避免 SVG 缩放和抗锯齿造成假越界。导出移除手机开孔时保留这项保护。

测试使用本地渲染的原图和样例，逐像素检查替换区域及保护区之外是否变化。测试预览宽度最多 720 像素；导出仍使用原尺寸。该检查验证边界保护，仍需目视检查是否框完整、背景衔接和文字外形是否合适。人工框错内容无法由边界检查自动纠正。

## 定位状态和失效规则

| 状态 | 含义与处理 |
| --- | --- |
| 未设置 | 尚未保存定位；保留原图可正常使用，原位修改前需定位 |
| 待确认 | 自动建议或手动草稿；不能据此原位替换 |
| 已确认 | 当前原图和区域已经测试，可在作图和批量页面复用 |
| 需重新确认 | 原图、比例或定位附近内容变化，需重新测试 |
| 不设置 | 当前模板明确不预设状态栏位置 |

修改任一区域、背景处理或保护区都会取消本次测试批准，需再次测试。取消窗口不会写入草稿。测试期间原图变化会拒绝保存过期结果。

定位使用标准化坐标。整个图片等比缩放且原内容保持同样位置时可继续使用；更换原图、非等比调整或改变定位区附近图层会失效。更改作品名称或不影响顶部的正文内容不会无故失效。

定位失效或生成图层与设置不一致时禁止导出旧的替换结果，可重新确认、保留原图或明确选择顶部新增。远程 URL 图片需要先保存为本地素材，避免远程文件内容变动而位置绑定未更新。

## 模板、作品和批量的关系

- 模板保存原图引用和定位元数据，不会把测试样例、清理底图或改后的时间烘焙进原图。
- 进入作图创建独立作品。作品内调整定位只影响该作品，不写回源模板。
- 批量默认复用所选模板的定位；在批量页面临时确认的位置只用于当前页面，不修改模板。需要长期复用时回模板保存。
- 批量结果在生成预览后固定。导出直接使用这批结果，不重新随机。修改规则或位置会使旧下载失效，需要重新预览。
- 模板文件、另存为模板和完整备份均携带定位。导入、恢复时重映射素材标识，同时保留位置绑定；原图文件内容不变。
- 旧模板仍可打开；已有旧版布局不自动改写。选择自然布局进行原位修改时，先完成定位确认。

## 推荐检查

放大检查时间左侧、旧 APP 边缘、系统图标右侧和下方标题。所有旧状态栏内容应被对应小区域涵盖，所有导航、胶囊和正文应在区域之外或保护区内。确认后先导出一张核对，再进行大批量生成。
