# 模板状态栏区域：框选后直接使用

更新日期：2026-10-26。

## 操作流程

1. 在模板编辑器打开 **状态栏定位 → 定位原状态栏**。
2. 使用自动建议，或手动调整外框、时间、APP、系统图标等区域。支持拖动、边界调整、坐标输入、放大、撤销和重做。
3. 直接点击 **确认并保存定位**，再保存模板。无需先测试，不再根据像素变化、空白内容、背景复杂度或区域重叠阻止确认。
4. 在单张作图或批量第 04 步设置型号、时间、电量、APP 等内容。后续按保存的标准化坐标处理。

**测试替换仅为可选预览。** 预览是否生成、像素统计及识别结果都不决定确认按钮能否使用。无法预览时仍可直接保存区域。

## 框选区域的作用

- 外框是处理范围，时间、APP、系统图标等小区域用于安排对应内容。小区域超出外框的部分不绘制到框外。
- 保护区保留原图；即使与内容框重叠也不拦截确认，输出时保护区优先。
- 时间与文字按框内空间缩放。APP 支持最多 8 个，按所选 APP 区域自动缩小、排列，不再因机型容量或区域窄而拦截。
- 日期、运营商只绘制在标记了对应区域的位置。未标记时不额外绘制，不阻止其他内容生成。
- 简单背景尽量采样匹配；复杂、空白或暂时无法读取的背景使用可用采样或画布底色。也可明确选择手动纯色，不以背景判断阻止确认。

区域是否合适由用户决定。原有内容不会因识别为空或疑似不是时间就阻止处理；需要清除哪些旧内容，应将其框进对应区域。复杂照片背景无法仅凭框选恢复被旧字遮住的原始纹理，可调整底色或先修图。

## 原图和导出

原图文件不被修改。预览、PNG 导出及批量输出使用像素掩膜，保留内容框与外框之外的原始 RGBA；保护区同样保留原图。小数坐标、缩略预览和 2×／3×导出使用同一规则。移除手机开孔时仍应用区域掩膜。

切换型号只更换系统参考样式，默认保持图片尺寸。已直接确认的区域在图片或画布变化后继续按标准化坐标使用，不再以原图变化拦截后续处理；需要改变位置时重新调整并保存即可。

## 保存与复用

- 模板记录原图引用、各区域和背景处理设置；确认后的测试样例不烘焙进原图。
- 单张作品是独立副本，作品内改动区域不会写回源模板。
- 批量默认复用模板区域，也可在当前批量页面临时调整；临时调整不修改模板。
- 批量预览生成后随机结果固定，ZIP 不重新随机；改变规则或区域后重新生成预览。
- 模板文件、另存为模板、历史版本和完整备份保留区域；导入或恢复时重映射素材引用。
- 旧版定位记录继续读取。重新打开区域并直接确认一次，即使用新的直接框选方式。
- 取消窗口不保存临时调整；已确认的区域需保存模板或作品，才能在刷新后继续使用。
