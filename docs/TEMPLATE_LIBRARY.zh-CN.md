## 使用

内置模板中的示例标识统一为 **海神作图 · 设计示例**，包含页眉、页脚、票面标识及交易模板醒目标识；保持原有可见性与导出显示。更新影响内置模板，新建作品会使用新标识；浏览器中已经保存的独立作品不会被自动改写。

转账类新增支付平台／银行、业务场景两级筛选，可组合关键词使用，筛选条件写入地址。批量页面也可按渠道和业务场景筛选，保留当前选择与规则。完整银行与场景说明见[转账模板配置](PAYMENT_TEMPLATES.zh-CN.md)。

- 模板库按分类显示数量；搜索同时匹配名称、分类、场景标签、说明和参数名称。多个关键词用空格分隔，例如“机票 东京”“证件 头像”。
- 每页显示 24 套，页码写入地址，刷新可保留页码；支持排序和收藏。预览只在接近可见区域时生成，避免一次渲染全部 331 套。
- 使用模板创建独立作品；修改金额、姓名、日期、头像等参数不修改内置原件。可另存为自己的模板。
- 批量页面也支持分类和关键词筛选。筛选不清空当前选中的模板和规则；当前选择不在筛选结果中时单独显示。
- 订单号使用 `DEMO-` 前缀与 10 位随机主体，默认批内去重。头像上传、裁剪、订单号随机与此前自定义参数功能相同。金额默认保留两位小数。
- 交易、机票、门票、证件和相关证书使用虚构示例数据，并在图片中标明示例或纪念用途。机票不生成真实可用登机码；证件卡牌不包含官方居民身份证、护照、防伪或机读区复刻。

## 开发维护

- `src/lib/template/collection.ts`：新增场景、字段、布局和主题配色，模板 ID 保持稳定。
- `src/lib/template/builtin.ts`：完整目录、分类和旧模板兼容。
- `src/lib/template/catalog.ts`：统一关键词匹配、分类统计和每页数量。
- 新模板应具有独立场景与字段，不应只改名字或颜色凑数量。字段必须绑定真实图层，默认值通过校验，文字区域不能越界或互相重叠。
- 新增分类时，同时检查模板库、首页入口、批量筛选与目录说明；图片资源如需新增，应本地化并保留对应许可。
