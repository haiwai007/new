## 使用

“惠民十五五”的入口为 `/templates?category=huimin-15`，在首页、模板库和批量分类中可选。此次仅新增空分类，未自动收录仓库中的三个模板文件。

- 支持分类、名称／参数关键词搜索、排序和收藏；手机端通过下拉选择分类。
- 每页最多 24 套，当前目录一页显示完毕，隐藏多余分页。预览接近可见区域时再生成。
- 使用模板创建独立作品，可编辑图层、填写参数、保存和导出图片，也可另存为自己的模板。
- 批量页面继续提供当前内置模板、自定义模板、分类与关键词筛选；筛选不清空当前参数规则。
- 旧的已下架分类链接回到全部可用模板；已下架内置模板 ID 不再解析为可用模板。

## 已保存的数据

此次调整只移除网站提供的内置预设，不扫描或删除浏览器中已保存的独立作品、自定义模板、素材、历史版本及备份。已保存作品的文字和图层也不会自动去掉或改写标识。

之前自行保存的副本仍可从“我的作品”“自定义模板”打开；模板文件与备份继续沿用原导入、导出流程。
