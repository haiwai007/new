# 海神作图 · 在线作图平台

海神作图是本地优先的在线作图平台，支持从参考图片生成可编辑模板、OCR 文字识别、图层与参数编辑、品牌手机状态栏适配，以及批量生成 PNG 并打包下载。核心功能无需注册，作品默认保存在当前浏览器；账户与云端备份为可选功能，未配置时明确显示“未启用”。

## 当前主要功能

- **模板参数自定义名称**：点击参数名称旁铅笔快速重命名，支持保存、取消与撤销；作图表单和批量规则使用新名称，保留原绑定与内容。
- **从图片生成模板**：上传 PNG / JPEG / WebP，选择 OCR 智能重建、原图背景或手动重建，生成可编辑图层和参数。
- **状态栏自然融合**：新设置默认自动分析顶部、匹配纯色或纵向渐变、调整布局与明暗；9 个版本参考样式，原图／效果局部对比，旧作品主动升级。
- **手机状态栏自动适配**：先选择品牌和具体型号，立即应用对应系统参考样式；支持自动取色、图片预览及旧状态栏覆盖高度调整，默认保留已选画布尺寸。
- **批量做图**：按固定值、随机区间、随机时间段、候选值或自动编号生成，每批最多 200 张 PNG，预览后打包 ZIP 下载。
- **指定型号随机**：勾选具体手机型号，支持独立随机和均衡分配，自动切换品牌系统布局；保持正文尺寸。
- **APP 通知随机**：固定＋指定候选、随机增加数量区间、排列顺序和自定义上传，按机型共同容量校验。
- **作图预设**：保存手机与随机规则，随完整备份迁移；模板制作不再显示手机设置。
- **状态栏单独随机**：可配置时间、日期、电量、信号、Wi-Fi、网络候选及附加图标；可独立于模板设置，预览与导出共用同一批结果，“换一批”重新抽取。
- **APP 通知图标**：内置快手、抖音、微信、QQ、小红书等 28 种图标，支持中英文搜索，可上传自定义图标，调整顺序、显示、大小与间距，并随模板和备份保存。
- **屏幕内容导出**：PNG / JPEG、尺寸倍率和 PNG 透明背景；手机图片保留状态栏与手势条，不包含外壳或硬件开孔。
- **本地数据管理**：作品、素材、撤销重做、历史版本、模板文件及完整备份；多标签页冲突自动另存副本。

## 启动

需要 Node.js 24、pnpm 11.25.0，版本已写入 `package.json`。在仓库根目录执行：

```bash
# 当前受限云环境使用以下三个缓存变量；普通电脑可省略。
export XDG_DATA_HOME=/workspace/.local/share
export XDG_CACHE_HOME=/workspace/.cache
export npm_config_store_dir=/workspace/.pnpm-store
pnpm install --frozen-lockfile
pnpm dev
```

默认端口 5173、站点根路径 `/`。可用 `PORT` 和 `BASE_PATH` 覆盖 Vite 设置；当前路由与部署验证基于根路径。没有配置服务时无需数据库、账户、API 密钥或 PostgreSQL。仓库保留的 Express / Drizzle 示例不参与编辑器的运行。

开发和构建命令都会执行 `scripts/prepare-ocr.mjs`：从锁文件固定并校验完整性的 npm 包复制 OCR Worker、WASM、中英文模型和许可证到生成目录，并校验内置照片的 SHA-256。重复执行会复用未变化的资源。不要手动修改生成资源或关闭安装、证书和文件校验。

所有内置照片、展示字体和 OCR 资源均由本站提供，正常本地流程不请求第三方 CDN。OCR 使用前仍会说明下载量、在浏览器本地处理并征求同意；首次加载约 10–15MB，后续可使用浏览器缓存。应用没有离线 Service Worker，不保证断网后的整个站点可重新加载。

为兼容已有作品，工程目录、浏览器存储键及文件内部格式标识保留原值；历史 `.caishen.json` 和 `.caishen-backup.json` 文件仍可导入，新导出文件使用海神作图名称和 `.haishen` 文件名。

## 功能与数据边界

| 页面 | 行为 |
| --- | --- |
| `/templates` | 内置可编辑模板。新建作品时将内置照片保存为本地素材，文件和备份可携带图片 |
| `/custom` | 图片上传、OCR 与模板重建；品牌 / 型号选择、状态栏自动配色和图片适配预览 |
| `/editor/:workId` | 文字、图片、形状、背景、图层、参数、撤销重做、历史版本及 PNG / JPEG 导出 |
| `/works` | 项目与自定义模板、收藏、复制、导入导出和导出记录 |
| `/assets` | 本地素材管理、分类、预览及引用检查 |
| `/batch` | 正文参数规则、状态栏独立随机、逐图校验和预览、PNG / ZIP 下载，最多 200 张 |
| `/backup` | 完整备份、预览、校验及创建副本恢复，无需登录 |
| `/account` | 可选真实登录、退出、手动云端上传、下载恢复及删除 |
| `/admin` | 服务端权限检查、用户和审计分页、上传维护开关及公告 |

作品和历史保存使用同一 IndexedDB 事务；手动保存与自动保存排队执行，防止较慢的预览生成覆盖后来的修改。跨标签页保存另有独立修订号校验与变更通知，冲突修改自动另存为副本，并提供打开入口；素材删除在事务内检查作品和历史引用。模板导入、云端副本恢复及整库恢复也以事务提交作品、版本和图片，失败时回滚。恢复和复制使用新的标识，已有记录不会被覆盖。

| 备份方式 | 包含内容 | 上限 |
| --- | --- | --- |
| 单个模板文件 `.haishen.json` | 当前文档、参数、引用的本地图片 | 80MB |
| 整库 `.haishen-backup.json` | 作品与模板、全部保留历史、图片素材库、导出记录、作图预设与内置模板收藏 | 100MB；不包含登录凭据、服务密钥或已下载的 PNG / JPEG 文件 |
| 云端单个作品 | 当前文档、参数和引用的本地图片 | 每账户 100 个，每个 8MB；不含历史、导出记录或未引用素材 |

整库恢复先校验格式、图片数据与引用关系，再展示数量；确认后在名称中添加“（备份恢复）”并创建副本。重复恢复会产生另一份副本。图片或历史丢失时拒绝导出完整备份，不产生看似成功但不完整的文件。模板中的自定义外部图片 URL 仍依赖对应站点，不会自动转换为文件；使用本地素材才能得到自包含备份。

云端是手动备份，不是后台自动合并。上传、删除和维护设置均检查版本，拒绝陈旧操作。维护暂停在服务端强制执行，但保留下载、删除自己的备份与本地编辑。新备份正文在 Convex 文件存储中，读取先验证账户归属，不公开永久文件 URL；替换、删除及失败写入会清理对应文件。兼容早期的 900KB 内联备份，重新上传后升级存储。

管理后台只对 `ADMIN_TOKEN_IDENTIFIERS` 中的服务端身份开放。审计记录成功的登录、备份创建/更新/删除和维护设置变更，不包含作品正文、图片或登录令牌。旧数据不会凭空补造审计记录。概览计数超过 100 时显示 `100+`，列表支持继续分页。此版本不提供角色编辑、用户删除或读取其他用户作品内容。

## 手机机型与状态栏

单张作图“手机”面板与批量作图支持 62 个具体型号，按 Apple、Samsung、Google、小米、Redmi、华为、荣耀、OPPO、一加、vivo、iQOO、realme 分组，选中型号立即切换系统参考状态栏。

其中安卓及鸿蒙机型 51 个，覆盖 Pixel、Galaxy S、Xiaomi、Redmi K / Note、Mate / Pura、荣耀 Magic、Find / Reno、一加数字 / Ace、vivo X、iQOO / Neo、realme GT 等具体系列。

可设置 24 / 12 小时时间、日期与星期、0–100% 电量、充电 / 低电量模式、百分比、信号与网络、运营商、蓝牙、定位、闹钟、静音、勿扰、VPN、HD 和双卡；支持图标颜色、大小、偏移、背景及手势条。Pixel、One UI 6 / 7、HyperOS、HarmonyOS、MagicOS、ColorOS、OriginOS、realme UI 分别使用系统参考图形和布局。系统版本、地区、主题及显示缩放会改变实际外观，不承诺逐台真机像素级一致，也不读取设备实际状态。

模板制作只处理内容；进入作图后可智能匹配顶栏配色，估算旧状态栏覆盖高度，或手动调整覆盖比例。保留原图、覆盖和添加状态栏是独立处理方式；添加模式增加顶部空间并下移正文，不拉伸内容。

选机型默认保留当前画布；勾选“同时适配机型画布尺寸”后，切换机型或点击重新应用才会调整分辨率。所有设置可撤销，随作品、历史版本、模板文件和备份保存，导出预览与 PNG / JPEG 图片只包含屏幕内容，保留时间、电量和手势条，不包含灵动岛、刘海或摄像头开孔；编辑器及模板备份保留开孔设置供设计参考。修改画布尺寸会自动让状态栏贴合新画布。

状态栏生成独立图层并默认锁定，可在图层面板解锁调整。重新应用会按面板设置重建并置顶；手动修改生成图层后再次应用会覆盖这些修改。“移除手机状态栏”移除其生成图层及关联参数；添加模式恢复正文位置和新增高度，不撤销另行主动调整的画布尺寸。自定义机身外框不包含在此功能中。

## APP 通知图标

在单张作图打开“手机”面板后，使用“APP 通知图标”区域搜索、选择内置图标或上传自定义图片。图库共有 28 种，原有快手、抖音、微信、QQ 等图标保持兼容。支持显示 / 隐藏、上移 / 下移、删除、大小及间距调整，最多 8 个。图标排列在时间旁，空间不足时自动收紧，避免挤到开孔和系统图标。

本次新增 20 种：小红书、淘宝、美团、知乎、豆瓣、百度、网易云音乐、钉钉、阿里旺旺、WhatsApp、Instagram、Facebook、Messenger、YouTube、Spotify、Discord、LINE、X、Zoom、Snapchat。搜索支持中文名称或英文标识，不区分英文大小写；图标选择区支持滚动。

内置图标使用单色品牌轮廓，跟随状态栏颜色；自定义图标保留上传颜色和透明度。上传支持 PNG / JPG / WebP，最大 2MB、1024×1024，推荐透明 PNG；应用会等比居中转换为 128×128 PNG 并保存在本地。

自定义图标随模板文件、完整备份和单作品文件携带，隐藏时也保留素材引用。恢复后重建素材标识，换机型和调整画布会重新适配。批量生成可沿用固定 APP，或设置固定＋随机候选与数量区间，包含自定义图标。APP 图标是额外设计元素，不代表所有系统的原生通知布局。

图标几何来自 Simple Icons、Ant Design Icons 和 Font Awesome，离线随站点提供。[来源与许可](artifacts/caishen-studio/public/attributions/statusbar-app-icons.txt)。

## 批量状态栏随机

任意内容模板都可在第 04 步“手机效果与随机规则”设置手机效果，不要求先为模板添加状态栏。支持固定型号、指定型号独立随机、均衡分配；APP 支持固定＋随机、数量区间、顺序与自定义上传，按最小共同容量校验。

| 随机项 | 配置方式 |
| --- | --- |
| 时间 | 分钟范围，支持跨午夜；起止相同则固定该时间 |
| 日期 | 有效日期范围，开启后显示日期，保留模板日期格式 |
| 电量 | 0–100 的整数范围，包含两端 |
| 信号与 Wi-Fi | 蜂窝 0–4 格；Wi-Fi 关闭或 1–3 格 |
| 网络类型 | 从已选候选中随机抽取 |
| 附加图标 | 充电、飞行模式、蓝牙、定位、闹钟、静音、勿扰、VPN、HD、双卡、低电量状态，勾选后各以 50% 概率开启 |

未启用的随机项使用固定设置，Wi-Fi、飞行模式仍遵循显示规则。修改规则后重新生成预览，支持逐张查看和重新随机；均衡分配下单张重抽保留型号。预览与 ZIP 使用同一批文档，导出不重抽，不修改原模板。作图预设存本地并随完整备份迁移。详见[使用指南](docs/BATCH_DRAWING.zh-CN.md)。

## 部署前端

完整操作步骤见[详细部署手册](docs/DEPLOYMENT.zh-CN.md)。可复制配置位于 [deploy](deploy/)，发布后运行 `node scripts/check-deployment.mjs https://你的域名 --full` 检查路由、资源类型及 OCR 摘要；这不替代浏览器验收或真实云服务联调。

执行 `pnpm build:studio`，将 `artifacts/caishen-studio/dist/public` 的完整内容部署到支持 HTTPS 的静态站点根目录。必须包含 `assets`、`ocr`、`templates` 和 `licenses`，不能只上传 `index.html`。当前完整产物较大，主要来自中英文字体和 OCR 引擎；浏览器按实际字符和功能加载所需资源。

主机必须将页面路由（例如 `/works`、`/editor/…`）回退到 `index.html`，同时正常提供真实静态文件和 MIME。已附 Netlify 兼容的 `_redirects` 与基本安全响应头；其他主机需配置等效规则。不要把 OCR `.js`、`.wasm`、`.gz` 或字体请求错误地重写为 HTML。部署应使用 HTTPS，以支持 Worker、剪贴板及安全上下文功能。

这份代码不自动发布站点，也不会创建付费服务、账户或凭据。

## 启用真实云端

1. 创建 Convex 部署和 Hercules 兼容的 OIDC 应用，将站点的 `/auth/callback` 注册为允许的回调。
2. 参照 `artifacts/caishen-studio/.env.example`，设置三个**公开**的构建变量：`VITE_CONVEX_URL`、`VITE_HERCULES_OIDC_AUTHORITY`、`VITE_HERCULES_OIDC_CLIENT_ID`。使用 HTTPS。浏览器构建变量不可存放密钥；修改后重启开发服务或重新构建。
3. 在 **Convex 服务端**设置匹配的 `HERCULES_OIDC_AUTHORITY` 与 `HERCULES_OIDC_CLIENT_ID`。
4. 在 `artifacts/caishen-studio` 中使用有部署权限的 Convex CLI 执行 `pnpm exec convex dev`，生产使用 `pnpm exec convex deploy`。需部署新的表、索引、`cloudFiles` actions、内部函数和审计维护逻辑。更新时先部署兼容的新后端，再更新前端。
5. 登录后打开 `/admin` 获取自己的完整账户标识，将允许访问后台的标识填入 **Convex 服务端**的 `ADMIN_TOKEN_IDENTIFIERS`，多个用英文逗号分隔。默认空值拒绝所有管理员。不要通过前端变量、邮箱匹配或客户端传入的角色授权。
6. 为实际 Convex 与 OIDC 域名配置必要网络访问。用两个真实账户验证隔离，再以同一账户在两个浏览器验证备份、恢复、冲突与维护暂停。

当前未创建或部署外部服务。真实 OIDC 登录、生产 Convex 网络和跨设备同步仍须配置后联调；本地测试不能代替这些验收。AI 照片级背景修复也未接入服务，现有背景修复为本地算法，不会模拟 AI 成功。

## 数据提醒

浏览器和站点之间的本地数据相互隔离；清理站点数据会删除本地作品，请先导出。退出账户不会删除本地作品，共用设备时请留意隐私。恢复始终创建副本；云端删除只删除指定备份。备份包含完整设计和图片，请妥善保存。

## 手动框选时保持原图清晰

手动重建默认以 100% 不透明度显示锁定的原图参考层；框选仅显示透明虚线边框，不淡化其他区域。旧手动模板若仍使用半透明参考层，编辑器顶部会出现“恢复原图清晰度”，点击后可保存，支持撤销重做。修复仅调整平台生成的原图参考层，不改变文字、参数或其他半透明设计图层。
