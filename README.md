# 海神作图

**本地优先的在线模板作图与批量图片生成平台。** 上传参考图片制作可编辑模板，填写参数生成单张作品，或按规则批量生成带手机状态栏的图片。

[在线使用](https://new-35o.pages.dev) · [详细部署手册](docs/DEPLOYMENT.zh-CN.md) · [作图与批量指南](docs/BATCH_DRAWING.zh-CN.md) · [验收记录](docs/ACCEPTANCE.md)

文档更新：2026-10-27。

## 项目定位

海神作图将“制作模板”和“使用模板作图”分开：模板负责图片、文字、图层、内容参数和原状态栏定位；作图页面负责具体内容与手机效果；批量页面负责生成张数、参数规则和随机设置。

核心作图功能无需注册，作品和素材默认保存在当前浏览器的 IndexedDB 中。前端可独立部署为静态网站，不需要数据库服务器或 API 密钥。账户、云端备份和管理后台属于可选服务，未配置时明确显示未启用。

默认首次打开网页需要完成文字确认，同一标签页内无需重复输入；启用内容后台后，管理员可修改弹窗内容、确认方式、显示频率，或关闭弹窗。

## 主要功能

新增 [Cloudflare 内容后台](docs/ADMIN_CMS.zh-CN.md)：管理员可管理公开分类、上传／发布共享模板和修改访问弹窗；前台访客无需登录。正式启用需绑定 D1、R2 并设置管理员密码摘要，未配置时明确显示未启用，内置模板和本地作图仍可使用。

模板库现有 **11 套、8 个分类**，新增“惠民十五五”分类，当前暂未收录模板。按用户要求，带“海神作图 · 设计示例”标识的 320 套内置模板已下架；已保存的独立作品与自定义模板保留。支持分类、关键词搜索、收藏和批量选择，详见[当前模板目录](docs/TEMPLATE_LIBRARY.zh-CN.md)。

| 功能         | 当前支持                                                                                |
| ------------ | --------------------------------------------------------------------------------------- |
| 图片制作模板 | 上传 PNG / JPEG / WebP，支持 OCR 智能重建、原图背景、手动重建                           |
| 图层编辑     | 文字、图片、形状、背景、图层顺序、锁定、撤销重做和历史版本                              |
| 模板参数     | 框选文字、数字、订单号、头像、Logo 与图片；自定义规则、默认值与多位置绑定                          |
| 单张作图     | 选择模板、填写内容、调整手机效果，导出 PNG / JPEG                                       |
| 批量作图     | 每批 1～200 张，支持固定值、候选值、随机区间、随机时间段和自动编号，生成 PNG 并打包 ZIP |
| 手机型号     | 按品牌选择 62 个具体型号，其中安卓及鸿蒙机型 51 个，使用对应系统的参考样式              |
| 状态栏适配   | 模板自动框选、手动调整、保护区与直接确认；在确认位置内替换时间与图标                    |
| APP 通知图标 | 内置微信、QQ、抖音、快手等 28 种图标，支持搜索、自定义上传、固定显示或指定候选随机      |
| 本地数据管理 | 作品、模板、素材、收藏、导出记录、模板文件及完整备份                                    |
| 保存冲突处理 | 跨标签页通知与版本校验，冲突修改另存副本，避免覆盖较新的作品                            |

订单号支持固定长度随机、前后缀和批内去重；头像与 Logo 支持上传、裁剪及恢复默认。模板试填内容与正式默认值分开保存。详见[模板参数与框选指南](docs/TEMPLATE_PARAMETERS.zh-CN.md)。

手动框选参数时保持原图清晰，只显示框选边界。旧手动模板若仍使用半透明参考层，可通过“恢复原图清晰度”修复并保存。

## 使用流程

### 制作模板

1. 打开“模板库”选用内置模板，或上传自己的参考图片。
2. 根据需要选择 OCR、原图背景或手动重建方式。
3. 编辑图层、框选参数，并为参数设置易于识别的名称。
4. 如需修改原状态栏，在“状态栏定位”检查自动框选或手动调整，直接确认保存；测试替换仅为可选预览。
5. 保存模板，进入作图时创建独立作品，不直接改动模板原件。

模板制作页面提供状态栏位置标记；型号、时间、电量和随机效果仍在作图与批量页面设置。详见[模板状态栏定位指南](docs/STATUS_BAR_LOCATION.zh-CN.md)。

### 单张作图

选择模板 → 填写内容参数 → 按需设置手机效果 → 保存或导出。

“手机”面板支持型号、时间、日期、电量、网络、APP 图标与配色等设置。自然布局按直接确认的框选区域处理，不再以像素变化、空白识别、背景复杂或原图变化拦截。单张作图保留原有作图预设功能。

### 批量作图

批量页面保留四个步骤：

| 步骤                      | 操作                                                 |
| ------------------------- | ---------------------------------------------------- |
| **01 选择模板**           | 选择内置模板或自己的模板                             |
| **02 生成张数**           | 设置本批次的图片数量                                 |
| **03 参数规则**           | 设置文字、数字、图片等内容参数的生成规则             |
| **04 手机效果与随机规则** | 选择是否修改状态栏，再独立设置型号、时间、电量和 APP |

第 04 步默认选择 **保留原图**，设置区收起。选择 **修改状态栏** 后显示四项：

| 设置项   | 固定设置                     | 随机设置                                              |
| -------- | ---------------------------- | ----------------------------------------------------- |
| 手机型号 | 按品牌选择一个具体型号       | 勾选候选型号，支持独立随机或均衡分配                  |
| 时间     | 所有图片使用同一个具体时间   | 设置开始、结束时间，支持跨午夜，例如 22:00～次日02:00 |
| 电量     | 输入固定百分比               | 设置最低、最高电量，在区间内抽取整数                  |
| APP 图标 | 勾选固定图标，也可选择不显示 | 勾选候选 APP，设置每张最少、最多数量，单张内不重复    |

各项独立切换，不需要开启额外的随机总开关。固定时间与随机区间分别保留，切换时不用重填。型号和 APP 候选列表支持选完后收起；APP 数量下限允许为 0，上限受候选数与最多 8 个的限制；直接确认的区域内自动缩放排列。

选择修改后复用模板已确认的位置，自动适配文字、图标和背景，默认保持图片尺寸，无需另点“应用状态栏”。未确认时框选并直接保存，无需测试通过；不使用顶部空白另加一套状态栏。批量中也可临时确认位置，只影响当前批次。

**更多设置**默认折叠，保留：

- 日期、时间制式、固定网络状态、充电、电池样式、配色及位置微调。
- 随机蜂窝信号（0～4 格）、Wi-Fi（关闭或 1～3 格）、网络类型。
- 随机充电、飞行模式、蓝牙、定位、闹钟、静音、勿扰、VPN、HD 高清通话、双卡信号和低电量模式。
- 明确选择顶部新增状态栏；该方式会下移正文并增加图片高度。

**批量修改状态栏时，低电量模式开启的图片电量不超过 20%。** 固定电量超过 20% 时限制为 20%；随机电量抽到超过 20% 时，改为在 0%～20% 内抽取。低电量模式关闭的图片继续遵循原设定范围。

第 04 底部显示一行设置摘要，不提供批量预设保存、读取或“使用上次设置”区域。

设置完成后点击 **生成预览**，检查每张结果，再生成并下载 ZIP。修改规则后需要重新生成预览；支持单张重新随机，均衡分配时保留该张型号。**导出使用当前预览结果，不重新随机。**

## 状态栏与导出说明

- 手机型号决定系统参考外形；高度和大小优先跟随模板，不直接套用真机分辨率。
- 提供 iOS、One UI、HyperOS、HarmonyOS 等参考样式及部分版本选择，不读取设备实际状态，也不识别截图的真实系统版本。
- 只清除已定位的小区域，保留其余内容及保护区；简单背景支持纯色或纵向渐变，复杂背景尽量采样，也可手动指定底色，不阻止确认。
- 自定义 APP 图标支持 PNG / JPEG / WebP，最大 2MB、1024×1024，等比居中转换为 PNG，保留透明度。
- 新建自然布局默认不添加底部手势条；切换型号不会自动打开已关闭的手势条，可按需手动开启。
- 导出只包含屏幕内容，保留状态栏和已启用的手势条，不包含手机外壳、灵动岛、刘海或摄像头开孔。
- PNG 支持透明导出，移除画布背景色和背景图；正常前景图层仍按自身内容渲染。

详细规则见[模板状态栏定位指南](docs/STATUS_BAR_LOCATION.zh-CN.md)、[状态栏自然融合指南](docs/STATUS_BAR_FUSION.zh-CN.md)与[手机型号目录](docs/PHONE_MODELS.zh-CN.md)。

## 本地开发

需要 **Node.js 24.x** 和 **pnpm 11.25.0**。在仓库根目录执行：

```bash
git clone https://github.com/haiwai007/new.git
cd new

# 已安装对应版本时可省略这一行。
npm install --global pnpm@11.25.0

pnpm install --frozen-lockfile --prod=false
pnpm dev
```

默认访问 `http://localhost:5173`。可通过 `PORT` 修改开发端口。项目当前按站点根路径 `/` 部署；`BASE_PATH` 不代表已经支持任意子目录路由。

开发与构建会自动运行 `scripts/prepare-ocr.mjs`，准备 OCR Worker、WASM、中英文模型、字体许可及内置照片校验。核心资源由本站提供，正常本地流程无需第三方字体、图片或 OCR CDN；首次使用 OCR 时会提示资源下载并在浏览器本地识别。

如需配置可选云端，环境文件放在 `artifacts/caishen-studio/.env.local`，参考同目录的 [.env.example](artifacts/caishen-studio/.env.example)。默认本地模式无需填写云端变量。

### 常用命令

```bash
# 工作区类型检查。
pnpm typecheck

# 可选后端的独立类型检查。
pnpm exec tsc -p artifacts/caishen-studio/convex/tsconfig.json --noEmit

# 单元、组件和本地 Convex 测试。
pnpm test:studio

# 构建前端。
pnpm build:studio

# 使用生产构建运行浏览器回归；先执行上面的构建命令。
E2E_PRODUCTION=1 pnpm test:e2e

# 本地预览构建产物。
PORT=4173 pnpm --filter @workspace/caishen-studio serve
```

浏览器测试默认使用 5174 端口。支持系统 Chromium，或通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定路径；需要下载浏览器时执行：

```bash
pnpm --filter @workspace/caishen-studio exec playwright install chromium
```

最近一次功能版本验收：**42 个测试文件、278 项自动化测试、36 项生产预览浏览器用例已回归验证**，并通过类型检查、生产构建和公网资源检查。覆盖实际 OCR、PNG / ZIP 导出、备份恢复、保存冲突、手机适配、批量随机及移动端。具体范围见[验收记录](docs/ACCEPTANCE.md)。

## Cloudflare Pages 部署

当前在线站点使用 Cloudflare Pages，并已关联本仓库的 `main` 分支。推送代码后，由 Cloudflare 自动构建和部署；使用自己的仓库时，需要先完成关联。

| 配置项         | 值                                     |
| -------------- | -------------------------------------- |
| 生产分支       | `main`                                 |
| 项目根目录     | 仓库根目录                             |
| 框架预设       | `None`                                 |
| 构建命令       | `pnpm build:studio`                    |
| 构建输出目录   | `artifacts/caishen-studio/dist/public` |
| `NODE_VERSION` | `24`                                   |
| `PNPM_VERSION` | `11.25.0`                              |
| `BASE_PATH`    | `/`                                    |

如果平台自动安装的 pnpm 版本不正确，可在支持的构建环境中设置 `SKIP_DEPENDENCY_INSTALL=1`，使用下列命令自行安装并构建：

```bash
npx --yes pnpm@11.25.0 install --frozen-lockfile --prod=false && npx --yes pnpm@11.25.0 build:studio
```

发布目录需要包含完整静态产物，而不只是 `index.html`。页面路由需要回退到首页，真实 JS、WASM、字体和 OCR 文件仍需按正确类型返回；公网使用 HTTPS。

发布后可执行：

```bash
node scripts/check-deployment.mjs https://你的域名 --full
```

Cloudflare 的实际构建结果以部署日志为准。GitHub Actions 提供代码验证，前端发布由关联的托管平台完成；只修改 GitHub 文件不会直接改写用户浏览器中的本地作品。

其他平台、自有服务器、Docker、域名、缓存、更新与回滚步骤见[详细部署手册](docs/DEPLOYMENT.zh-CN.md)，示例配置位于 [deploy](deploy/)。

## 数据保存与迁移

| 方式                            | 内容与限制                                                                        |
| ------------------------------- | --------------------------------------------------------------------------------- |
| 浏览器本地保存                  | 当前浏览器、当前站点下的作品、模板、历史和素材                                    |
| 单个模板文件 `.haishen.json`    | 当前文档、参数和引用的本地图片，文件上限 80MB                                     |
| 完整备份 `.haishen-backup.json` | 作品、模板、历史、素材、导出记录、作图预设和内置模板收藏，文件上限 100MB          |
| 可选云端作品备份                | 当前文档及引用的本地图片，每账户最多 100 个、每个 8MB；不包含完整历史和未引用素材 |

完整备份不包含登录凭据、服务密钥或已经下载的 PNG / JPEG 文件。恢复先校验并预览，再创建副本，不覆盖原有记录。旧 `.caishen.json` 与 `.caishen-backup.json` 文件继续兼容。

更换浏览器、设备或网站域名不会自动搬迁本地数据，清理站点数据也会删除本地作品；迁移前请导出完整备份。自定义外部图片 URL 仍依赖对应站点，本地素材才能随文件完整携带。应用没有离线 Service Worker，不保证断网后可以重新打开整个网站。

## 可选账户、云端与管理后台

默认静态部署即可使用本地作图功能。云端方案需要另行配置 **Convex 与 Hercules 兼容的 OIDC 服务**：

- 前端公开构建变量：`VITE_CONVEX_URL`、`VITE_HERCULES_OIDC_AUTHORITY`、`VITE_HERCULES_OIDC_CLIENT_ID`。
- Convex 服务端需配置匹配的 OIDC 信息；管理员通过服务端 `ADMIN_TOKEN_IDENTIFIERS` 授权。
- 云端采用手动上传、下载恢复和删除，不是后台自动合并或实时同步。
- 未配置的服务明确显示未启用，不模拟登录、上传或云端成功。

前端 `VITE_*` 变量会进入浏览器产物，不能放入密钥。真实账户隔离、生产网络和跨设备备份需要在配置服务后联调；本地测试不替代这些验证。完整配置见[部署手册的云端章节](docs/DEPLOYMENT.zh-CN.md#11-可选-convex-与-oidc)。

## 工程结构

主要使用 React、TypeScript、Vite、Tailwind CSS、Fabric.js、Zustand、IndexedDB 和 Tesseract.js；可选后端使用 Convex 与 OIDC。

```text
artifacts/caishen-studio/
├── src/                  作图、模板、批量页面及本地存储逻辑
├── public/               静态图片、图标来源说明及发布资源
├── convex/               可选账户、云端备份、审计及管理逻辑
├── e2e/                  Playwright 浏览器回归
└── dist/public/           生成的前端发布目录
scripts/                  OCR 资源准备及部署检查
deploy/                  静态托管、Docker 与 Nginx 配置示例
docs/                    功能、部署和验收说明
```

仓库保留的 `artifacts/api-server`、`lib/db` 等示例工程不是当前作图平台的运行依赖。发布前端使用 `pnpm build:studio`；工程目录和部分内部格式保留历史名称，以兼容已有数据。
