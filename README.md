# 海神作图

在线模板制作与单张、批量作图平台。上传图片，框选可编辑区域，设置文字、编号或图片参数，再按规则生成作品。

**[在线使用](https://xiaohai.uk) · [教学视频与素材](https://xiaohai.uk/tutorial/index.html) · [使用指南](docs/USER_GUIDE.zh-CN.md) · [Cloudflare 部署](docs/DEPLOYMENT.zh-CN.md)**

## 功能

| 模块 | 支持内容 |
| --- | --- |
| 模板制作 | 图片上传、浏览器本地 OCR、手动框选、图层编辑、自动保存、撤销重做 |
| 模板参数 | 自定义名称、文字、金额、编号、脱敏卡号、日期时间（可到秒）、头像与 Logo |
| 参数框调整 | 多选对齐、等宽等高、等间距、固定基准框及精确位置调整 |
| 单张与批量 | 同一作图工作台，固定内容、候选随机、区间随机、编号规则、PNG／ZIP 导出 |
| 手机效果 | 型号与系统样式选择、状态栏区域替换、时间电量与 APP 图标随机、自定义图标 |
| 模板分享 | 访客免登录投稿，管理员查看实际效果后审核发布 |
| 管理后台 | 分类、共享模板、投稿审核、访问弹窗、管理员密码管理 |
| 数据管理 | 本地作品与素材、模板导入导出、完整备份、保存冲突提示 |

核心作图无需登录，个人作品默认保存在当前浏览器。公开模板、投稿与后台设置使用 Cloudflare D1 和 R2。外部服务未配置时明确显示未启用。

手机效果提供 100 个型号、268 个型号版本记录及 140 个 APP 图标（国内 98、国外 42）。型号配置不等于逐台真机核准，已知范围见[校准资料](docs/phone-calibration/README.md)。

## 快速使用

1. 在模板页选择模板，或上传图片制作自己的模板。
2. 框选参数，设置名称、正式默认值、生成规则与原内容处理方式。
3. 点击“进入作图”，生成张数填 `1` 为单张，填多个为批量。
4. 设置内容；需要时开启“修改状态栏”，默认保留原图。
5. 生成预览并放大检查，再导出图片。导出沿用预览，不重新随机。

分享模板时，通过编辑器“更多 → 导出模板文件（含图片）”获取 `.haishen.json`，再到“提交模板”上传审核。普通图片不包含可编辑参数。

## 本地开发

需要 **Node.js 24.x、pnpm 11.25.0**，在仓库根目录执行：

```bash
pnpm install --frozen-lockfile --prod=false
pnpm dev
```

默认访问 `http://localhost:5173`。开发、构建会自动准备本地 OCR 与字体资源。

```bash
pnpm typecheck       # 前端、Cloudflare 服务端与可选云端类型检查
pnpm test:studio     # 单元与组件测试
pnpm build:studio    # 生成 artifacts/caishen-studio/dist/public
```

浏览器测试、后台本地验证及维护脚本见[开发说明](docs/DEVELOPMENT.zh-CN.md)。

## 部署

当前使用 **GitHub main → Cloudflare Pages 自动部署**；D1 保存公开目录和后台设置，私有 R2 保存模板文件。唯一部署教程为[Cloudflare 部署指南](docs/DEPLOYMENT.zh-CN.md)，包含首次配置、更新、验证和回滚。

## 数据与兼容

- 个人作品与素材保存在当前浏览器、当前域名下；更换设备或域名前请导出完整备份。
- 模板文件包含引用的本地图片；完整备份还包含作品、历史、素材等本地数据。
- 旧 `.caishen.json`、旧备份与已保存模板继续兼容。
- 后台模板下架不会删除访客已保存的独立副本。
- 可选账户及云端备份代码继续保留，默认本地作图不依赖它们。
